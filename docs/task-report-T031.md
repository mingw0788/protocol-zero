## 实现内容

1. 有效命中后敌人及 Boss 闪白 0.09 秒，非致死命中产生 3 个有界火花。脉冲枪、磁轨炮有短时枪口与后坐反馈；沿用真实射击朝向。表现由模拟步推进，暂停冻结、重开清除。
2. 弧光线圈、磁轨炮、中继冲击拥有独立声音事件。增加可配置快速起音、频率瞬态与峰值，击杀声由方波改为较低音量三角波；8 声部上限不变，玩家受伤、死亡和胜败提示可抢占较低优先级声部，并释放其节点。
3. 东城区增加医疗广场、变电庭院、疏散集结区三个可通行地标与一次性中继。中心距 64 内累计 2 秒后治疗 15 HP，180 范围（计入敌人半径）冲击普通敌人 60 / Boss 30。治疗不超上限、不复活；满血仍可触发冲击；站点不重复结算。死亡与经验统一复用已有管线。此项是新增区域收益，未改既有武器伤害或敌人参数。
4. 地面圆环显示蓄能、冲击和耗尽状态；HUD 提示最近未耗尽中继的方向、距离或蓄能进度；帮助页说明规则。
5. 地图重复街区及实验室陈设按视口剔除，块编号与图案保持稳定，不改变战斗随机流。
