## 修改与审查修复

| 审查发现 | 修复 | 防回归证据 |
|---|---|---|
| 三张进化卡同时抽中时，强化保底在候选数组上写入索引 `-1`，无法提供合法强化。 | 全进化候选时替换最后一张卡；仍保留至少一项强化和一项进化。 | 三张卡均为进化的确定性抽样回归用例。 |

| 精英挑战在无尽时生成的新 EN-06 没有乘当前无尽生命倍率。 | 复用同一波次 HP 倍率创建精英配置，同时保留原敌数、单精英和地图边界限制。 | 无尽第十分钟倍率 2.5 时，精英生命应为 550 的集成回归用例。 |

存档策略保留了已有兼容性：一般 V2 `normalizeProgress` 对**未出现**的新增字段仍按旧内部调用方式补默认值；实际 V2 导入则要求导出格式中的记录、发现列表、成就和外观字段齐全。对原始本机数据中的任何未知版本都拒绝写入，避免静默损坏未来存档。

## 浏览器操作与异常

本地开发构建在 Windows 11 / Intel Core i5-1155G7（4核8线程、16 GiB 内存、Intel Iris Xe）运行。Edge 152 使用有窗口模式；Chrome 155 使用无窗口模式。Edge 首次交互测试与 Chrome 重跑各自使用隔离浏览器上下文。

两浏览器检查了640×360主菜单、帮助、战斗 HUD、暂停、升级、结算与本地图鉴；窗口宽度不发生横向溢出。通过真实的 Playwright 按键流程验证移动、Shift、Esc、升级重抽/快捷选择、E/Q 两道具和 G 跟踪。派发 `blur` 浏览器事件后自动暂停；模拟时间被冻结，回焦不会自行恢复。浏览器路由中只为测试临时获取 Game 引用，产品入口没有新增自动化钩子。

使用界面流程建立胜利，再继续无尽、主动结束并检查原胜利记录仍为胜利；十次连续重开后再逐轮触发一次受控玩家失败，验证各轮仍只有单次事件。导出文件完成真实下载/导入确认往返；坏数据不弹出替换确认且不改当前档案。两浏览器页面错误数均为0。

Playwright 启动本机 Chrome 有窗口实例时，该进程由本机 Chrome 退出并记录 `NOTREACHED`。使用同版 Chrome 155 无窗口自动化后完整通过，因此报告不声称 Chrome 有窗口通过。合成 blur/focus 事件验证了网页事件路径，真实 OS 标签切换仍未验证。

## 完整帧与内存测量

压力画像由实际 `GameLoop` 帧回调驱动，并计时 `GameWorld.update`、画布渲染、音乐更新、HUD DOM 更新以及一次 DOM 布局读取。预热60帧后分别量360帧。夹具用正常敌种、Boss和合法系统接口构造六武器/四进化；玩家无敌时间和Boss当前生命由夹具回填。每帧在计时以外补足普通敌数到100。这衡量给定浏览器/机器的完整脚本帧耗时，不测屏幕实际合成或 GPU 驱动显示完成时间。

| 浏览器 | 完整回调耗时 P50 / P95 / 最大 | RAF 间隔 P50 / P95 / 最大 | 本地夹具同时上限 |
|---|---:|---:|---|
| Edge 152 有窗口 | 3.4 / 5.6 / 7.8 毫秒 | 16.7 / 16.9 / 17.1 毫秒 | 100普通敌、1 Boss、64敌弹、10玩家弹、3无人机弹、228晶体、24补给、320粒子、48伤害数字、1条能量带、2炮台 |
| Chrome 155 无窗口 | 3.6 / 4.9 / 7.7 毫秒 | 16.7 / 16.8 / 33.3 毫秒 | 100普通敌、1 Boss、64敌弹、10玩家弹、3无人机弹、230晶体、24补给、320粒子、48伤害数字、1条能量带、2炮台 |

计时 P95 在 16.7毫秒一帧目标以内；Chrome RAF 记录中出现33.3毫秒一帧间隔，较早一轮 Edge 重采样也出现33.4毫秒间隔。因而这次测量**不证明持续60 FPS**，只证明这次受控图片中的脚本部分开销和运行浏览器帧调度。每帧 Canvas 命令已完整进入计时，但像素真正显示、独立实际试玩和其他机器仍须评估。

浏览器脚本每60个样本读取一次可见 JS 堆。Edge 六次值约9.3–12.0 MiB，Chrome 值见 `output/t045-chrome-performance.log`，会受工作集和回收时点影响。强制垃圾回收后，观察到的堆量仍比启动测值分别高约1.1 MiB / 1.4 MiB；这只是短测前后对比，不能据此断言有或没有长时间泄漏。长时间固定步状态量和 reset 清理另以自动测试断言。

可复核脚本/图像均保存在被 git 忽略的 `output/playwright/` 与 `output/`；未纳入程序功能依赖。
