## 1. 项目背景与目标

2149 年，由中央人工智能「主脑」管理的城市爆发失控协议。大批机械单位被感染。玩家扮演自主维护战斗机器人 ZERO，深入废弃科技区域，战胜机械敌群，抵达对抗机械暴君的最终时刻。

**产品目标：** 实现可以通过网页直接打开、具有完整单局循环、无需在线账号或付费 API 的原创单机游戏。玩法重点是自动攻击、走位闪避、经验拾取、随机升级、击败 Boss。

**完整用户旅程：** 主菜单 → 开始 → 自动攻击与生存 → 敌人死亡掉落经验 → 升级三选一 → 敌群压力升级 → Boss → 胜利或失败结算 → 重开/返回菜单。

## 2. 版本范围

### 2.1 V1 必须交付

- 1 个可操控角色 ZERO，初始生命、经验与移动属性。
- 1 张「废弃科技实验室」有限地图，摄像机跟随角色。
- 3 种普通敌人：普通感染体、迅捷猎犬、重装机甲。
- 2 种武器：开局脉冲枪，升级后可解锁轨道刃。
- 6 类随机升级：火力强化、极速装填、多重脉冲、轨道刃模块、机动优化、纳米装甲。
- 1 个单阶段 Boss「机械暴君 T-01」。
- 五分钟生存挑战及明确的胜败判定。
- 主菜单、操作说明、HUD、暂停、升级三选一、胜利、失败、重新开始。
- 像素风视觉、基础音效、最高击杀和最佳通关成绩本地保存。

### 2.2 V1 不做（严格禁止顺手增加）

- 账号登录/注册、多玩家联机、联网排行榜、支付、后端数据库。
- 多地图、开放世界、角色职业、多阶段 Boss、剧情过场、全程语音。
- 超载协议、冲刺、武器进化、天赋树、商店或复杂背包。
- 付费 AI 接口、云存档、复杂地图寻路、重型游戏引擎。

### 2.3 后续版本候选

V1.1 优先平衡与画面优化；V2 可增加冲刺、新武器、地图和 Boss；V3 可加入超载协议、武器进化、长期成长、12 分钟完整模式。**后续版本不构成 V1 验收范围。**

## 3. 核心游戏规则

### 3.1 游戏流程与胜负

- 一局从 `PLAYING` 开始计时，有效战斗时间单位为秒。
- 4 分 30 秒（270 秒）时只生成一次 Boss。
- 时间达到至少 5 分钟（300 秒）**并且** Boss 已死亡时，玩家获胜。
- 如果 300 秒时 Boss 仍未死亡，继续战斗直到击败 Boss 或玩家死亡。
- 玩家当前生命值 `<= 0` 时失败。若同一次模拟更新中同时满足玩家死亡与胜利，**玩家死亡优先**。
- `PAUSED`、`LEVEL_UP`、`MENU`、结算状态不推进有效时间，也不推进攻击冷却、AI、生成、粒子模拟等战局行为。
- 重新开始必须清空本局玩家增益、武器状态、所有实体、计时器和一次性事件标记，保留本地音频偏好与历史成绩。

### 3.2 操作与响应

| 输入 | 行为 | 备注 |
|---|---|---|
| W/A/S/D | 上左下右移动 | 支持组合按键 |
| ↑←↓→ | 上左下右移动 | 与 WASD 等效 |
| Esc | 在 PLAYING ↔ PAUSED 切换 | LEVEL_UP 中不允许 Esc 跳过升级 |
| 鼠标 | 菜单、升级选择与设置 | 移动和攻击无需鼠标 |
| 自动 | 武器攻击最近有效目标 | 射程内没有敌人时不攻击 |

- 斜向移动向量归一化，不比水平或垂直移动更快。
- 角色不能走出合法地图范围。
- 浏览器窗口失去焦点或标签页隐藏时，游戏自动进入 `PAUSED`；回到页面后保持暂停，须由玩家手动继续；失焦期间不补算战斗时间。

### 3.3 玩家初始属性（平衡初稿）

| 属性 | V1 初始值 |
|---|---:|
| 最大生命 | 100 |
| 当前生命 | 100 |
| 移动速度 | 220 世界像素/秒 |
| 碰撞半径 | 16 世界像素（可配置的首轮占位值） |
| 初始位置 | 地图中心 `(1200, 675)` 世界坐标 |
| 初始等级 | 1 |
| 初始经验 | 0 |
| 初始装备 | 脉冲枪 |
| 脉冲枪基础伤害 | 20 |
| 脉冲枪基础频率 | 1.25 发/秒 |
| 玩家受击无敌时间 | 0.6 秒 |

以上属于**可调参数**，不得在业务逻辑里硬编码多个版本。

### 3.4 敌人（平衡初稿）

| ID / 名称 | 生命 | 速度（像素/秒） | 半径（世界像素） | 接触伤害 | 掉落经验 | 行为 |
|---|---:|---:|---:|---:|---:|---|
| EN-01 普通感染体 | 30 | 80 | 16 | 10 | 1 | 平稳追踪 |
| EN-02 迅捷猎犬 | 18 | 155 | 待 T014 配置 | 8 | 1 | 高速追踪 |
| EN-03 重装机甲 | 100 | 55 | 待 T014 配置 | 18 | 3 | 慢速高生命追踪 |
| BOSS-01 机械暴君 T-01 | 1800 | 配置决定 | 配置决定 | 配置决定 | 无需经验 | 追踪+蓄力冲锋 |

- 普通敌人从摄像机当前视口之外、地图合法范围内生成；不得直接出现在玩家碰撞区域内。
- 普通敌人活跃数量初定上限 **100**（Boss 不计入），作为性能目标基线。
- T006 EN-01 首轮生成间隔为每有效 1 秒 1 个名额，首个名额在有效时间到达 1 秒时产生；敌人外缘距逻辑视口至少 32 世界像素。以上为用户确认的可配置首轮值（D-023），完整波次/频率曲线由 T014 配置。
- 死亡后只计入一次击杀和经验掉落。
- Boss 为单阶段，冲锋攻击前提供至少 **0.7 秒**可辨识预警，并有独立血条。

### 3.5 地图与视口

- 地图：废弃科技实验室，有限区域，暂定 **2400 × 1350 世界像素**。
- 逻辑视口参考尺寸 **1280 × 720**，根据浏览器实际尺寸等比缩放并居中留边，避免非等比拉伸；Canvas 后备位图按 CSS 尺寸与设备像素比调整。
- 摄像机跟随玩家并受地图边界限制。世界坐标负责碰撞/运动，屏幕坐标仅负责绘制/UI。
- V1 地面纹理、发光电路、破损设备主要为**装饰**，不引入复杂障碍与寻路系统。

### 3.6 经验与升级

- 击杀敌人生成可拾取的经验晶体，按配置提供经验值。
- 每个正经验值的敌人死亡事件在死亡坐标产生一枚晶体，经验值等于敌人配置的 `expDrop`；`expDrop` 为 0 时不生成。敌人死亡事件由 T008 的单次结算保证不重复发放。
- 玩家存活且玩家圆形与晶体拾取圆相交时立即拾取，中心距离判定为 `≤ player.radius + pickupRadius`。不做磁吸。拾取半径首轮配置值为 12 世界像素；晶体占位图为可配置的琥珀色 8×8 方块，正式美术留给 T017。
- 晶体的有效战局寿命首轮配置值为 120 秒；只有有效模拟步推进寿命，暂停或玩家死亡冻结期间不计时，到期后静默清理。重新开始时清空本局所有晶体。
- 从当前等级 L 升到下一级的经验需求：`6 + 4 × (L - 1)`。
- `player.exp` 表示当前等级的经验余量。每跨过一个阈值即扣除该级所需经验并将等级加 1；剩余经验继续与新等级的阈值比较。
- 经验达到阈值时暂停战场并触发一次升级选择；多余经验保留。每跨过一个阈值对应一次独立选择。
- 一次获取若足够连续升级多次，必须依次完成每一次的升级选择，不能丢失升级次数。
- 三个候选选项必须互不重复、合法且未达到各自等级上限。候选不足 3 个时显示剩余可选项；全部满级后提供可重复的生命恢复保底项（恢复至生命上限，不提高上限）。
- 实际升级速度、经验掉落可在 M2–M4 试玩后调整，升级必须能够看出明确的武器/属性变化。

### 3.7 武器

**脉冲枪（开局已装备）**：射程内查找最近有效敌人，自动射出直线子弹；基础伤害 20，攻击速度 1.25 发/秒。多重脉冲升级追加弹丸；攻击频率与弹丸数量各有等级上限。

**轨道刃（升级解锁）**：围绕玩家旋转的近距离范围武器；首次选择「轨道刃模块」时解锁，重复选择强化其伤害/覆盖半径。对同一敌人必须有独立命中冷却，不能每一模拟帧无限扣血。

不同武器共享通用伤害修正，但使用各自的攻击逻辑；不得直接修改全局基础武器配置。

### 3.8 六类升级（初步平衡参数）

| ID | 类型 | 效果 | 建议等级上限 |
|---|---|---|---:|
| UP-01 | 火力强化 | 全武器基础伤害 +15%（按统一属性规则叠加） | 5 |
| UP-02 | 极速装填 | 脉冲枪攻击速度 +12% | 5 |
| UP-03 | 多重脉冲 | 每次脉冲攻击额外 +1 枚弹丸，额外弹丸上限 2 | 2 |
| UP-04 | 轨道刃模块 | 首次解锁；其后提升轨道刃效果 | 5 |
| UP-05 | 机动优化 | 移动速度 +8% | 5 |
| UP-06 | 纳米装甲 | 最大生命 +20 且恢复 20 生命（不能超上限） | 5 |

- 升级伤害、频率和速度按配置明确顺序计算，叠加策略在系统设计中保持一致。
- UP-03 意味着最多 **3 枚总弹丸**（基础 1 + 额外 2），不得与此前的“上限三枚”产生理解分歧。

### 3.9 波次与节奏

| 有效时间 | 波次内容 |
|---|---|
| 0:00–1:00 | 普通感染体；适应移动与攻击 |
| 1:00–2:00 | 引入迅捷猎犬 |
| 2:00–3:00 | 引入重装机甲 |
| 3:00–4:00 | 混合敌群，增加生成速率 |
| 4:00–4:30 | 高压生存 |
| 4:30–5:00 | Boss 到场，最终挑战 |
| 5:00 之后 | 若 Boss 未死继续战斗直至胜/败 |

普通敌人生成频率以可配置曲线控制，不能直接写在渲染层。V1 不要求随机地图生成。

## 5. UI/UX 需求

| 场景 | 内容与交互 | 特别约束 |
|---|---|---|
| 主菜单 | 游戏名、开始、操作说明、音效 | 不需要登录 |
| 战斗 HUD | 生命、经验、等级、时间、击杀、当前武器 | 信息清晰、不能挡住主要战场 |
| 升级弹窗 | 3 个不同升级选项的名称、效果和等级 | 升级期间冻结战局，Esc 无法跳过 |

| Boss HUD | Boss 名称、生命条、预警 | 不遮挡危险区域 |
| 胜利结算 | 击杀数、存活时间、重开/回菜单 | 仅满足条件才显示 |
| 失败结算 | 击杀数、存活时间、重开/回菜单 | 玩家死亡优先判定 |

统一 UI 使用赛博朋克黑蓝底色、玩家青蓝、敌人红、奖励紫、精英金的视觉系统。像素素材清晰度优先，避免粒子和伤害数字把人物遮住。

## 7. 验收方案

### 7.1 战局功能验收

- [ ] 菜单可以开始游戏；暂停、恢复、返回主菜单正确。
- [ ] 八方向移动正确，地图边界有效；切标签页不会导致卡键和异常时间跳跃。
- [ ] 三类敌人能按波次生成、追踪，不在玩家碰撞范围内生成。
- [ ] 脉冲枪自动开火，轨道刃能解锁和攻击，敌人死亡只计击杀/掉落一次。
- [ ] 接触伤害、0.6 秒无敌时间和玩家死亡正确。
- [ ] 经验掉落和拾取正确；升级阈值及连续升级正确。
- [ ] 升级三选一不重复、不超等级上限；六类效果真实生效。
- [ ] Boss 在 270 秒时生成一次，并提供至少 0.7 秒冲锋预警。
- [ ] 300 秒后 Boss 已死判胜；Boss 未死继续战斗；同周期死亡优先失败。
- [ ] 结束时显示正确数据；连续重新开始无状态污染。

### 7.2 交付验收

- [ ] 已替换关键占位素材，保持统一赛博朋克像素风。
- [ ] 音效不阻断游戏，音量设置和成绩可以安全本地保存。
- [ ] Chrome 与 Edge 人工测试，主要单元/集成测试通过。
- [ ] 记录高密度敌群性能结果，阻断性缺陷为零。
- [ ] 生产构建成功并可在静态站点打开；README 和操作说明准确。

## 8. 测试与需求变更约定

需求数字（敌人生命、升级加成、掉落等）为首轮平衡配置，开发和试玩阶段允许在**记录原因、更新配置与文档**后调优。不允许在未获明确指令时新增 V2/V3 功能。若需求冲突，先在 `docs/decisions.md` 记录并确认。
