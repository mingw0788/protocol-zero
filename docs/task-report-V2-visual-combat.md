# T029 · 地图、武器与打击反馈打磨

**日期：** 2026-10-13
**分支：** `codex/v2-visual-combat-feedback`
**基线：** V2 内容包分支 `fc81bbb`

## 用户反馈与处理边界

用户反馈地图过于单一、武器需要可见、打击声音不理想。此次按视觉/音频表现层处理：地图陈设都是非碰撞装饰；武器外观直接读取已有战局装备状态；命中音只反馈已接受的攻击伤害。不改变伤害、攻击冷却、移动、敌人 AI、升级机会、胜败条件或存档。

## 实现

- `MapRenderer` 增加城区街区、不同屋顶、窗带、绿地、设备点、路缘、斑马线、道路残车和交通障碍标识；实验室增加成组设备舱、控制台及电缆标线。道路交叉口和原地图边界保持开放，所有新增内容只绘制，不进入碰撞。
- `PlayerRenderer` 按 `player.weaponStates` 绘制青色脉冲枪、紫色弧光线圈、金色磁轨炮挂载模块。轨道刃沿用原有绕身表现；首次升级解锁时才显示对应新模块。
- `EnemyDamageSystem` 对成功应用的伤害发出冻结通知。`GameWorld` 对非致死命中使用 0.1 秒战局时间间隔限频后发出 `weapon-hit`；致死命中继续播放原有敌人死亡音，避免双音叠加。暂停不推进限频时钟，重开复位限频状态。
- `AudioManager` 继续使用原 Web Audio 合成链路和最多 8 个并发声部；新增短促三角波下滑音，用于区分开火提示和有效命中。
