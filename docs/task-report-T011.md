# T011 交付报告：升级三选一界面

**日期：** 2026-10-12  
**状态：** 实现、自动化验收、独立审查修复与文档交付完成；自然升级流程的浏览器交互未验证
**设计与计划：** `docs/superpowers/specs/2026-10-12-t011-upgrade-choice-design.md`、`docs/superpowers/plans/2026-10-12-t011-upgrade-choice.md`

## 完成范围

- 新增集中冻结的六类升级配置及 `UpgradeSystem`，按 D-030 对当前合法、未满级选项等权无放回抽取最多三个候选；候选快照只读，抽样随机源与敌人生成分离。
- `GameWorld` 在进入 `LEVEL_UP` 前准备候选；每次有效选择只消费一个待选升级，仍有队列时马上换一组候选并保持战场冻结，队列清空后恢复 `PLAYING`。无效选项或错误状态不改变游戏数据。
- 全部升级满级后提供可重复的满血恢复选项，不增加生命上限或升级等级。
- `Game` 提供只读候选与选择动作；`UIManager` 用固定 DOM 卡片呈现升级名称、等级和说明，不直接修改领域状态。对话框使用模态语义和剩余次数提示；鼠标、Enter、Space 直接选择，Tab 焦点限制在可见选项，Escape 不会关闭升级界面或跳过队列（D-031）。
- 实际升级数值和玩家/脉冲枪属性效果归 T012，轨道刃攻击归 T013；T011 没有改动已确认的玩法数值。

## 验证结果

- 自动化回归：`npm test`，32 个测试文件、225 项通过。覆盖升级配置与抽样、随机流隔离、等级上限、满级恢复、状态接线、逐项队列冻结、重开清理及 UI 键盘/显隐等行为。
- 生产构建：`npm run build` 通过，Vite 转换 42 个模块。
- 差异检查：`git diff --check` 通过；仅有工作区 LF/CRLF 提示。
- 浏览器：在本地 Vite 页面使用 Playwright 浏览器确认标题菜单、开始游戏、战斗 HUD 正常；最终控制台统计为 0 错误、0 警告。没有安装项目依赖。
- **未验证项：** 两次自然战斗都未在死亡前收集到升级所需的 6 点经验。第一次于战斗 20 秒、10 击杀、3 经验时死亡；第二次主动走位后于战斗 44 秒、25 击杀、3 经验时死亡。因此升级卡片的实际浏览器显示、鼠标/Enter/Space 选择、Escape 锁定以及多项选择后的浏览器恢复流程仍未验证。自动化单元/集成测试覆盖了这些状态与交互；完整浏览器场景留给 T020/T021 的全流程回归继续尝试，不把自动化结果表述成浏览器证据。

## 独立审查与修正

对 T011 变更范围 `0b353c1..49652d7` 的只读独立审查没有发现 Critical 问题，提出两项 Important 修正：

1. 默认升级抽样与敌人生成都引用全局 `Math.random`，候选生成会消耗敌人生成序列。现已给每局升级系统创建独立随机流，并增加默认构造下的隔离回归测试；显式注入仍可为升级单独提供随机函数。
2. 实施计划误记原生 Enter/Space 已经由浏览器验证，与本报告的自然升级限制冲突。已更正为未验证，并说明卡片在两次试玩中未出现。

按执行流程对 Important 项在同一轮修正后直接复验，未再安排第二轮审查。独立审查对升级面板实际浏览器绘制和操作明确列为未评估；本报告保留未验证状态，后续 T020/T021 继续承担全流程回归。
