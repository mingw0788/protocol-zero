## 浏览器与性能证据

环境为 **Windows 11 家庭版 10.0.26200**，两浏览器通过 Playwright 无头模式访问本机 Vite 页面，DPR 1，逻辑/绘制画布 **1280×720**，报告中的菜单额外检查 **640×360**。`navigator.hardwareConcurrency` 返回 8；未固定或记录显卡型号，Canvas 结果不可跨设备外推。浏览器证据不是 T021 的静态部署验收。

### Chrome

- Chrome 程序版本 `154.0.8037.98`；Playwright UA `HeadlessChrome/154.0.0.0`。
- 菜单 640×360 测得面板高约 332.4 CSS 像素、页面无垂直溢出；1280×720 无溢出。
- 开始/HUD/自动战斗、帮助、静音/恢复、音量滑杆、受控升级卡、Esc 锁定、暂停计时冻结和手动继续、返回主菜单取消/确认、重开与损坏存档回退均完成浏览器操作验证。
- 浏览器会话中通过真实 UI 触发三轮清局重开；每轮回 MENU 后计时为 00:00。
- 失焦模拟：向页面派发 `visibilitychange` 并切换 `document.hidden`；暂停立即出现、计时冻结，切回可见仍不自动继续。该事件层验证通过，但并未证明 Windows 实际切换标签页/最小化窗口的可见性状态。
- 常规应用浏览器日志 0 错误 / 0 警告。受控克隆 UI fixture 同时存在另一个有焦点 UI 时有 1 条 INFO（浏览器提示 autofocus 被阻止），0 错误 / 0 警告；不是应用异常。
- 页面资源请求无外部 origin。

### Microsoft Edge

- Edge 程序版本 `152.0.4191.53`；Playwright UA `Edg/152.0.0.0`。
- 菜单 1280×720；开始/HUD、受控隐藏事件暂停并冻结 1 秒、返回可见继续保持暂停、手动恢复到 00:02、Esc 暂停、返回对话框取消/确认、回菜单、640×360 无页面溢出均通过。
- 控制台 0 错误 / 0 警告；页面资源请求无外部 origin。

### 隔离 Canvas 绘制计时

每个浏览器均使用当前真实 `CanvasRenderer`、Canvas 2D、1280×720、DPR 1；预热 30 帧、采样 300 帧。场景含 100 普通敌人、1 个预警态 Boss、100 经验晶体、100 投射物、320 粒子、玩家和轨道刃。耗时只包住同步 `render()` 调用。

| 浏览器 | 中位数 | 平均 | P95 | P99 | P95 倒数换算吞吐 |
|---|---:|---:|---:|---:|---:|
| Chrome 154 | 3.5 ms | 3.329 ms | 5.6 ms | 7.6 ms | 178.6 次绘制/秒 |
| Edge 152 | 2.6 ms | 2.673 ms | 4.3 ms | 5.3 ms | 232.6 次绘制/秒 |

倒数换算是隔离绘制基准的等效吞吐，不是现场整局实际 FPS，也不包括固定步更新、DOM 更新、GPU 合成或其他系统成本。两组 P95 均低于 16.67 ms 绘制预算，未显示需要进行玩法外的针对性优化。

### 实体生命周期和重置

- Edge 内直接运行 30 轮独立 `GameWorld`，每轮 300 个 `1/60` 秒更新步；每轮负载 100 个普通敌人、100 个短寿命弹丸和 100 个待过期晶体；晶体有效期到期后从实体集合移除。
- 每轮放入 1 个死亡实体，累计恰好 30 个击杀事件和 30 个敌人死亡声音事件，未见 reset 订阅倍增。
- 每轮主动发射 320 粒子，计数不超过配置上限；轮末 `GameWorld.reset()` 后 enemies、projectiles、experienceCrystals、visualEffects 均为 0。
- Edge 最终一次 `performance.memory.usedJSHeapSize` 读数约 8.43 MB；无同条件基准前值/强制 GC，因此只记录瞬时值，不推断无内存泄漏。
- 压测与自然战斗画面测试期间未观察到浏览器错误/警告。

- **真实标签切换限制：** Playwright 上下文打开第二页面时，原页面报告仍为 `document.hidden === false`、`visibilityState === "visible"`，没有触发真实后台标签页生命周期；因此只用受控 `visibilitychange` 事件验证应用监听与手动恢复，未标记系统级标签切换已验收。
- **平衡遗留：** 这次自然输入尝试未达到 6 点经验升级门槛。保持现有已确认参数，不在 T020 擅自削弱敌人或提高玩家属性；将玩法平衡留作后续基于多轮试玩的评估，不作为已修复项。
- **性能遗留：** 没有独立 GPU 型号、完整整帧 FPS 曲线、长时间 GC 后内存曲线；这些测量未由隔离 Canvas 数据推导。
- **无阻断缺陷：** 回归、重置、数据回退、核心 UI 与绘制基准均未发现阻止 T021 的软件错误。生产静态站点的构建/打开/运行仍归 T021。
