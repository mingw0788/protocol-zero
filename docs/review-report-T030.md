## 已修复问题

脉冲枪原先随移动朝向绘制，磁轨炮固定斜向绘制，但两者实际自动瞄准最近合法敌人。角色背向目标移动时，枪口与实际攻击方向明显不符。

现在由 WeaponSystem / RailgunSystem 在真实开火时记录武器的 `aimAngle`，PlayerRenderer 只读该值。首次开火前沿角色朝向，冷却期间保持最近开火方向；重开清除战局朝向。不改变角色移动朝向、选靶、伤害和射击节奏；多弹脉冲枪沿散布中心方向显示。

变更文件：`src/systems/WeaponSystem.js`、`src/systems/RailgunSystem.js`、`src/systems/weaponTargeting.js`、`src/rendering/PlayerRenderer.js`、`tests/player-renderer.test.js` 及配套项目文档。另补记 T029 已有提交哈希，移除过期交付占位。
