# T010 经验等级与连续升级队列交付报告

- **Task ID：** T010 — 经验阈值和连续升级。
- **执行状态：** 完成；范围内实现、自动化验证、生产构建与独立审查问题修复均已完成。

## 实现内容

- 按 `6 + 4 × (当前等级 − 1)` 计算阈值；`player.exp` 表示当前等级余量，跨级时消费阈值并保留剩余经验。
- 一次经验入账可以跨越多个递增阈值；每次跨级立即增加等级，并新增一个待选升级。
- 累计阈值使用精确整数运算和对数步数查找，避免超大经验值按级同步循环卡住主线程。Number 安全整数范围之外的阈值或最终等级/队列结果会以 `RangeError` 原子拒绝，不部分修改玩家或队列；这属于表示精度边界，不是玩法等级上限。
- 新增受控 `LEVEL_UP` 状态。队列未清空前，模拟、时钟、敌人、弹丸和晶体更新均冻结；普通暂停、继续和返回菜单迁移不能跳过该状态。
- 当前固定步先结算拾取和阈值，再推进时钟与步数，最后进入升级状态；GameLoop 停止同帧剩余补算步。
- HUD 冻结快照新增只读 `pendingLevelUps`。升级选择挂起期间 `GameWorld.reset()` 在修改数据前拒绝，避免清空队列却留下无退出路径的冻结状态；合法重置仍由既有流程恢复等级 1、经验 0。
- T010 不含升级卡片 UI、候选项抽取或属性奖励；这些由 T011/T012 实现。
