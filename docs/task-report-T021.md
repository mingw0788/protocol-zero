### 发布安全与边界

- Sites 源码远端为服务单独创建的仓库；`dist/` 静态归档单独部署。站点改为公开访问以满足分享试玩，未设置游戏后端、登录、付费 API 或运行期外部资源。
- 项目没有 `LICENSE`，源码不获得默示的开源复用许可；内置视觉为原创代码图案，声音由浏览器 Web Audio 合成。
- Git 源码历史不配置共享的 GitHub 远端；托管 helper 只推送 Site 绑定的独立源码仓库，归档只包含静态输出。
