### 本地生产静态预览

- 命令：`npm run build` 后 `npm run preview -- --host 127.0.0.1`。
- 构建：Vite 8.3.4 转换 60 个模块；`dist/index.html` 7,910 字节、CSS 8,814 字节、JS 93,396 字节；浏览器请求入口和两个带哈希资源均成功。
- Chrome：HeadlessChrome 154.0.0.0（T020 的安装版本为 154.0.8037.98）；Edge：HeadlessChrome 152.0.0.0 / Edg 152.0.0.0（T020 的安装版本为 152.0.4191.53）。
- 两个浏览器均从自然开局走到真实失败结算，再来一局后 HUD 时间回到 00:00；这仅确认终局/重开可用，不表示自然五分钟获胜。T020 中 00:32 / 16 击杀的平衡限制仍有效。
- 控制台异常：Chrome 0，Edge 0；运行时请求 origin：仅本机静态预览；外部游戏 API：无。
