## 交付内容

- 新增版本 1 `LocalProgressStore`，使用 `protocol-zero.save` 键；持久化字段仅为最高击杀、最快胜利用时、音效开关和音量。
- 严格验证 JSON、schema 版本、安全整数击杀、有限获胜时间、布尔静音和 0–1 音量；无存档、损坏/未知版本、非法字段及存储访问/读写异常都安全回默认。写入失败不会使游戏崩溃。
- 新增 `LocalProgressSystem`。它加载一次并暴露冻结快照，在真实胜败结算事件发生后更新最高击杀；仅胜利记录刷新最快通关时间。失败局不影响最快胜利记录。
- 音量/静音改变时即时保存；GameWorld reset、重开与回菜单不清除用户记录。未保存位置、HP、经验、升级、敌人或其它中途战局状态。
- 主菜单新增最高击杀与最佳通关文本，未有胜利记录时显示“尚无”。保留当前项目的中文语义控件及短屏布局。

## 决策

D-016 采用 T000 原审查建议：任何正式结束局参与最高击杀比较，仅 victory 参与最佳通关时间比较，较小的 `elapsedSeconds` 为佳。D-039 记录存档键、版本及安全默认策略。该决定只定义记录口径，不修改任何玩法或胜败规则。
