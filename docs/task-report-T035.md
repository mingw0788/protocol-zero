## 交付

主动道具自动填入两个槽，E/Q 分别使用；C 切换高亮槽而不使用，F 与 64 世界像素内最近主动道具原子交换。两槽满时地面物品保留；交换出的旧物保留 60 秒。范围外、空槽使用和电芯无可用中继均提示原因。F 与使用同一步输入时只交换。HUD/帮助/README 已同步。

SupplySystem 拥有槽位与选中状态，InputController 管理一次按下请求，GameWorld 固定步编排。公开快照冻结槽位及最近可交换物；`activeItem` 暂留为 slot0 兼容别名。pause、LEVEL_UP、失焦清输入，reset 清两槽/特效/提示。
