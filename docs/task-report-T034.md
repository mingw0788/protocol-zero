## 实现内容

- 新增 `CombatStatsSystem`，汇总每来源实际敌人生命伤害、敌种击杀、玩家实际生命损失、护盾吸收及敌种来袭统计。
- `EnemyDamageSystem.applyDamage` 增加可选来源 ID，同时保持原布尔返回值。伤害事件保留请求伤害并新增实际扣血、目标类别/类型和来源；实际扣血最高只计敌人剩余生命。
- 脉冲枪、轨道刃、弧光线圈、磁轨炮、EMP 和中继冲击均使用稳定来源 ID。Enemy 持有最近有效伤害来源，GameWorld 单次死亡结算记录一次来源击杀。
- DamageSystem 返回实际护盾吸收与最高接触伤害来源；接触伤害仍只取一份最大值。并列敌种对承伤来源统计均分，不重复统计总量。
- 统计 reset 清零；正式胜/败结果包含冻结统计快照。既有公开敌人死亡事件字段与格式保持不变，HUD/UI 暂不展示。
