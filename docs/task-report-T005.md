## 2. 实现内容

1. 页面启动停留标题主菜单；提供开始、操作说明和声音偏好开关，点击开始才进入 PLAYING。
2. Player 持有真实生命 100/100、等级 1、经验 0 和脉冲枪装备状态；GameWorld 汇总玩家、有效时钟和本局击杀，返回防修改副本。
3. HUD 只读快照并显示生命、经验、等级、有效存活时间、击杀和装备。每帧接收快照，只有展示值变化才更新 DOM。
4. Esc 暂停/继续；重复按键不连续切换，MENU 中 Esc 不开始游戏。已有失焦安全暂停会同步显示暂停界面，恢复焦点不会自动继续。
5. 返回菜单使用原生确认对话框；取消或 Esc 仅关闭确认并保持 PAUSED。确认先清理本局再回菜单，重新开始恢复初值。活动局重复调用开始不会重置。
6. UI 生命周期清理监听和订阅；缺失所需控件时给出描述性错误，入口显示可见启动错误。标题、帮助、暂停、HUD 采用独立 DOM 层，Canvas 继续绘制世界。
7. 声音默认开启；开关保存本次页面运行期偏好，返回菜单保留设置。当前没有可听音效或持久化。
