## 交付范围

- 以冻结的内嵌像素矩阵绘制 ZERO、三种普通敌人与 T-01；加入最近邻绘制、未知类型回退、有效时间动画、玩家受击反馈、Boss 警告表现，以及晶体/弹丸/轨道刃细节。碰撞尺寸和玩法值未更改。
- 新增确定性 ParticleSystem，源于已结算的敌人死亡和真实玩家受伤；活动数量最多 320、寿命 0.45 秒。粒子只在有效固定步推进，快照不可变；暂停、升级/终局冻结和重开规则保持一致。
- 玩家终局爆发在生成时就预先展开，因为失败后模拟不再运行；粒子系统复制并冻结经过校验的配置，避免外部修改破坏上限。
- 为地图增加固定位置的纯装饰电路线条；优化 HUD、菜单和结算区在窄视口的间距与焦点反馈。640×360 的终局操作无需滚动即可看到。
- 无外部图片、音频素材或新增依赖；无玩法、伤害、碰撞、胜败或实体属性变更。
