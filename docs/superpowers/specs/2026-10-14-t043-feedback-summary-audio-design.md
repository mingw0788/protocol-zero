# T043 反馈、结算、教学与音频设计

授权路线的体验批次，战斗规则和随机序列保持独立于表现设置。

- 新增可切换伤害数字（默认开）、减少闪光（默认关）、强化危险提示（默认开）、教学提示（默认开）。设置放在菜单折叠区和暂停页，单独版本化本机保存；存储失败不影响游玩，未知版本不覆盖。
- DamageNumberSystem 记录实际有效伤害，最多48条、0.65秒寿命，同目标/类型0.08秒内合并。世界固定步推进，暂停冻结、重开清除。关闭仅影响绘制，数字不改变统计或随机。
- 减少闪光取消角色/敌人/Boss白色闪烁和枪口白光，保留静态轮廓、危险形状、血条及音效。强化危险增加预警线宽/标记，关闭仍保留基本预警。现有未实现全屏震动，不新增震动。
- 暂停页显示武器/进化、全部已选升级、过载/中继/装置剩余时间和待用增幅；结算显示有效伤害、DPS、承伤/护盾、各来源伤害占比及击杀，探索/事件维持原统计。
- 教学用不阻断战斗的小提示，前60秒依次说明移动/冲刺、经验/升级、双槽/探索/事件，可永久关闭并从设置重新启用；详细说明仍在操作帮助。
- 音乐独立音量默认20%，音效沿用原音量/优先级。AudioManager复用一个AudioContext，音乐最多3个连续合成声部，以游戏有效时间驱动四和弦/短琶音循环，Boss时增加层次。无网络音频或素材依赖。
- 非PLAYING立即停止音乐节点，继续时重建有界声部；静音/音乐0音量/销毁释放节点。无AudioContext静默回退，危险音效仍可抢占较低优先级音效，音乐不占8个短音效额度。

验收：设置校验/保存失败/未知版本、关闭表现不改变真实伤害，数字合并/上限/冻结/reset；暂停与结果数据口径；音乐懒初始化、独立音量、暂停/静音/销毁无节点累积；浏览器正常和窄窗口操作。
