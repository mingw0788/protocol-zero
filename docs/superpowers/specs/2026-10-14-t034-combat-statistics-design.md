# T034 战斗统计与伤害归属设计

日期：2026-10-14。状态：随用户授权执行扩展路线实施；数值和统计口径为提案首轮定义。

## 目标

提供本局可复核的输出/承伤摘要，为新敌人、武器和后续结算信息建立统一统计来源。只记录现有战斗结果，不改变武器输出、敌人生命、生命/护盾扣除、接触伤害选最大值、无敌时间、死亡事件、击杀与经验规则。

## 统计口径

- 武器输出按真实扣除敌人生命的数值累计；击杀过量伤害只累计剩余生命，不累计请求伤害。已死亡目标拒绝后续伤害，统计不增加。
- 伤害来源固定使用稳定 ID：`pulse-gun`、`orbital-blade`、`arc-coil`、`railgun`、`emp-charge`、`relay-pulse`、`unknown`。`unknown` 是未来/第三方调用的兼容回退。
- 目标统计按 `typeId` 累加一次正式死亡；来源击杀归给致死伤害来源。死亡结算幂等仍由 GameWorld 管理，Boss 计入击杀和武器统计。
- 玩家承伤继续使用当前固定步“接触敌人最大单体伤害”规则。只统计实际扣除的生命值与护盾值；被冲刺/无敌挡下的命中不计入。
- 接触伤害来源归给达到最大 `contactDamage` 的敌人类型；并列最大则来源 ID 列表按稳定字符串排序。治疗不计作负伤害。
- 每局 reset 清零全部战斗统计；暂停、升级、结算不推进统计。公开敌人死亡事件保持既有 schema。

## 架构

- 新增纯状态 `CombatStatsSystem`，只接受不可变数据事件，持有计数 Map，不读取/修改实体或配置。
- `EnemyDamageSystem.applyDamage(enemy, damage, sourceId)` 保持布尔返回值并写入敌人最近伤害来源；通知包含请求伤害、实际生命伤害、目标类别与来源。观察者抛错不得中断伤害。
- 已有武器/道具/中继在伤害入口传入自身来源 ID。来源经校验；省略时使用 `unknown`。
- `DamageSystem` 保持原接触伤害算法，并在结果补充实际护盾吸收量与最大伤害来源类型；无伤害返回零统计字段。
- GameWorld 在真实伤害/正式死亡处更新 CombatStatsSystem；重开调用 reset；结果快照附带冻结统计摘要，但旧死亡监听器数据结构不变。
- 排序快照按伤害/击杀降序，同值按 ID 升序，保证确定性。

## 测试重点

- 过量击杀伤害只计剩余生命；无效/死敌目标不增加统计。
- 各伤害系统来源分配正确，Boss/普通敌人死亡各只结算一次。
- 多个接触目标仍只取最大伤害，来源并列稳定；护盾吸收和生命伤害分别准确。
- 观察者失败不影响伤害；快照深冻结；reset/重开清零；暂停不改统计。
- 已有公开死亡事件字段、敌人 HP 与 T007 同帧战斗结果保持兼容。

## 用户可见性与范围

T034 只生成可供 UI 后续消费的结果快照，不新增结算 UI；展示由 T043 完成。当前 UI 不出现半成品统计。

## 风险

击杀归属不等于对 Boss 造成的总贡献，尤其有共享/反射伤害时可能误导平衡。本轮按实际致死来源归属；T043 展示时应使用“最后一击”语义或只展示伤害比例，不将其解释为完整击杀贡献。
