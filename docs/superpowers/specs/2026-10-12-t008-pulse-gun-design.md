# T008 脉冲枪自动攻击设计

**状态：** 设计已由用户逐节确认，2026-10-12

**任务：** T008 — 脉冲枪自动攻击

**前置：** T006 敌人系统、T007 玩家受伤和碰撞

## 1. 目标与边界

在现有固定步长战局中加入玩家的初始自动武器“脉冲枪”。它会在有效射程内选择最近的存活敌人，按固定射速发射直线弹丸；弹丸命中敌人后造成伤害。敌人死亡时由 `GameWorld` 只结算一次击杀，并同步发出不可变死亡快照，为 T009 提供掉落入口。

本任务交付武器配置、目标选择、射击冷却、弹丸移动/寿命/命中、敌方伤害、死亡结算与击杀计数，以及对应的绘制和验证。T008 不创建经验晶体、不拾取经验、不修改升级或既定玩法，也不实现 T017 的正式视觉效果。

## 2. 已确认的规则与首轮参数

| 项目 | 规则 / 数值 |
|---|---|
| 自动瞄准 | 选择射程内中心距离最近的合法敌人；无需攻击输入 |
| 合法目标 | `alive === true`、`hp > 0` 且位置有效的敌人 |
| 脉冲枪伤害 | 每发 20 点（SRS 固定） |
| 射速 | 1.25 发/秒，即 0.8 秒间隔（SRS 固定） |
| 射程 | 640 世界像素，按玩家中心到敌人中心测量 |
| 弹丸速度 | 500 世界像素/秒 |
| 弹丸碰撞半径 | 4 世界像素 |
| 弹丸寿命 | 1.28 秒；按速度计算的最大行程为 640 世界像素 |
| 首发时机 | 武器可用且出现合法目标时立即发射；之后按 0.8 秒间隔 |
| 冷却 | 无目标时继续按有效模拟时间倒计时；暂停时不倒计时 |
| 飞行 | 发射时锁定方向，直线飞行，不追踪、不穿透；命中后消失 |
| 绘制 | 使用简单青色方块作为功能占位；正式润色由 T017 负责 |

射程、速度、半径和寿命是可配置的首轮值；不借此扩展武器升级或改变 SRS 已固定的伤害、射速和自动瞄准玩法。相同距离的目标按当前稳定敌人数组中的先后顺序决定，以保证每步结果可复现。

## 3. 模块职责与数据归属

- `PULSE_GUN_CONFIG`：集中保存脉冲枪伤害、射击间隔、射程、弹丸速度/半径/寿命和占位颜色；配置只读。所有要求为正值的数值均须为有限正数。
- 玩家每局武器状态：每个武器实例有独立的冷却余量；初始冷却为零。有效模拟步推进冷却，`Player.reset()`/`GameWorld.reset()` 清零。状态属于玩家本局数据，不写回共享配置。
- `WeaponSystem`：取得当前可用武器，选择最近合法目标，按冷却决定是否开火；只创建弹丸并追加到战局弹丸集合，不直接修改敌人生命。
- `Projectile`：记录稳定 ID、所有者/武器 ID、世界坐标、速度向量、碰撞半径、伤害、剩余寿命和活动状态；不持有 DOM、Canvas、时钟或游戏 UI。
- `ProjectileSystem`：仅在有效模拟步推进弹丸，按飞行线段与敌人圆形碰撞体求交，处理寿命并移除失效弹丸。速度和寿命按有效模拟时间计算。
- `EnemyDamageSystem`：只对仍存活的敌人应用弹丸伤害；生命下限为零，生命归零时将敌人标为死亡。重复命中已经死亡的敌人不重复应用效果。
- `GameWorld`：拥有弹丸集合和以上战斗系统，负责固定步调用顺序、死亡幂等结算、击杀计数与死亡事件。渲染层不反向导入战斗系统。
- `ProjectileRenderer`：只读弹丸，在地图与敌人之间绘制青色方块并裁剪到逻辑视口；不改变实体或模拟状态。

冷却应落在玩家各自的本局武器状态中，不能放进共享配置或模块级全局变量。现有 HUD 仍通过只读快照读取玩家武器 ID 和 GameWorld 击杀数；UI 不直接读取或修改冷却、弹丸或敌人状态。

## 4. 固定步数据流

仅当 `GameWorld.update(deltaSeconds)` 开始时处于 `PLAYING` 且玩家死亡冻结未启用，战斗系统才推进。继续沿用 T002 的 1/60 秒固定步、每帧最多 5 步和 T007 的有效模拟时间口径；不得使用墙钟计时器。

每个有效模拟步按以下顺序处理：

1. 推进玩家无敌时间并更新玩家位置，再同步相机。
2. 在任何敌人清理前检查尚未结算的死亡，然后清理失效实体；生成敌人并更新其追踪。
3. 按 T007 现有顺序，使用移动后的玩家/敌人位置结算玩家接触伤害；这保持敌人在本步仍有机会造成接触伤害的既有规则。
4. 用移动后的玩家和敌人位置选择目标，更新武器冷却并生成弹丸。首发立即进行；无目标时不发射，但冷却仍递减。
5. 推进弹丸并检测命中。弹丸只使用发射时确定的方向；碰撞按弹丸本步移动线段与敌人圆形的最近交点判定，以避免高速穿透。若路径与多个敌人相交，只命中行进方向上最先接触者；相同交点按敌人数组顺序决定。命中后的弹丸不再检查后续目标。
6. 对所有新死亡敌人执行一次死亡结算，再清理死亡/失效实体。结算前设置 `deathProcessed`，增加 `GameWorld.recordKill()`，然后同步通知订阅者。
7. 按 T007 现有规则完成有效时钟和模拟步计数；若玩家本步死亡，则清理输入并冻结后续模拟步。本步在进入冻结前完成，与现有 T007 致死步口径一致。

若弹丸本步的 delta 超过剩余寿命，只沿有效寿命对应的那段轨迹检测碰撞，然后过期；不能在过期之后继续命中。弹丸起点已经落在敌人碰撞圆内时，按起点处的交点命中。无效/死亡敌人不参与选靶或命中。

暂停、菜单、失焦暂停、玩家死亡冻结期间不推进武器、冷却、弹丸或敌人；T007 的每局时钟规则不变。新局重置时清空弹丸及冷却，死亡事件订阅关系保留；不补发上一局历史事件。

## 5. 死亡事件与清理

`GameWorld` 提供与玩家死亡订阅风格一致的 `subscribeEnemyDeath(listener)`：校验监听器类型，返回取消订阅函数；事件同步触发、不重放历史记录，订阅关系跨 `reset()` 保留。

每次敌人死亡通知使用新建且冻结的值对象：

```js
{ enemyId, typeId, x, y, expDrop }
```

事件中的坐标和经验掉落值取自死亡结算时的敌人快照，不能暴露可被外部修改的敌人实体。`deathProcessed` 在计数和通知之前设置，以保证同一敌人即使多系统重复发现死亡也只增加一次击杀并只发送一次事件。死亡处理必须早于 `EnemySystem.cleanup()` 删除实体。

T008 只提供事件，不由该事件创建经验晶体；T009 订阅此接口并承担掉落与拾取逻辑。

## 6. 校验、性能与错误边界

- 武器数值配置在构造/系统初始化时校验；射程、伤害、射速间隔、弹丸速度、半径和寿命均为有限正数。非法配置立即抛出明确错误，不能静默产生 NaN 或无限弹丸。
- 更新 delta 必须有限且非负；零 delta 不推进冷却、位置或寿命。
- 目标/碰撞仅使用有限坐标与仍存活、正生命的敌人；选取和碰撞基于世界坐标，不依赖 CSS、DPR 或渲染帧率。
- 每发弹丸有有限寿命，过期、命中或被 reset 时立即从战局集合清除；不增加对象池，也不引入依赖。
- 在已确认敌人上限 100 的前提下使用线性遍历，不引入空间索引。每次最多按在途弹丸数乘敌人数检测，首轮射速和寿命使在途弹丸数量自然受限。
- 渲染器只处理当前活动且视口内弹丸，并裁剪到逻辑视口；模拟是否正确不依赖是否挂载渲染器。

## 7. 验证与验收

### 单元验证

- 无目标不开火；目标在射程边界内可选、边界外不可选；死亡或零生命敌人不能选中。
- 多目标选中中心距离最近者；相等距离按稳定数组顺序处理。
- 冷却初值允许有目标时立即首射；射击间隔符合 0.8 秒；无目标仍减少冷却；暂停/零 delta 不减少冷却。
- 弹丸方向、速度、生命周期、过期清理正确；大步长使用线段检测不穿透；只击中最近交点并且不穿透；起点重叠可命中。
- 单次命中扣除 20 点；重复伤害把生命钳制到零；同一敌人死亡只记录一次击杀和一次冻结通知。
- reset 清空弹丸、冷却和本局击杀，保留敌人死亡事件订阅且不重放旧事件。
- 暂停和玩家死亡冻结时弹丸位置、冷却与有效时间停止推进。
- 弹丸绘制使用相机世界/屏幕映射，在视口外裁剪；渲染不修改战斗实体。

### 集成与浏览器验收

- 在 `GameWorld` 固定步中形成自动瞄准 → 发射 → 命中 → 敌人死亡 → 击杀计数/只读事件 → 清理的闭环；普通 EN-01 需要符合 30 HP 与每发 20 点的既定数据。
- 使用现有浏览器验证工作流实际开局，观察脉冲枪自动发射、命中反馈和击杀 HUD；确认暂停、继续、返回菜单后新开局不会残留旧弹丸/冷却，且监听可接收新一局死亡事件。
- 不声称本任务完成 Chrome/Edge 全量兼容、长局压力或正式视觉验收；这些由 T020/T017 负责。

### 验收标准

玩家不按攻击键时，脉冲枪会自动攻击射程内最近的存活普通敌人；弹丸按配置移动、命中并造成 20 点伤害；敌人被击败后只增加一次击杀并产生一条供 T009 使用的不可变死亡通知。暂停/死亡冻结和重开规则符合本规格。

## 8. 明确不在 T008 范围

- 经验晶体实体、掉落绘制、吸附/拾取和经验增加（T009）。
- 经验等级、升级选择与升级对武器属性的影响（T010–T013）。
- 轨道刃、Boss 武器、伤害数字、爆炸/枪口特效、音效与正式弹丸美术。
- 修改玩家移动、敌人属性、固定步策略、自动瞄准目标规则或 SRS 固定伤害/射速。
- 新增第三方依赖、对象池、服务端或持久化。
