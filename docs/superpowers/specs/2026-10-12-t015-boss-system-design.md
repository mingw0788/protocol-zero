# T015 机械暴君 T-01 设计规格

**日期：** 2026-10-12  
**状态：** 实现、自动化与受控浏览器验收完成；报告见 `docs/task-report-T015.md`
**任务：** T015 — 机械暴君 T-01

## 目标与约束

在有效战局时间到达 270 秒时只生成一次机械暴君 T-01。它加入既有敌人战斗管线，可被脉冲枪和轨道刃命中，接触玩家造成伤害，并循环执行追踪、可辨识预警、冲锋和恢复。Boss 显示独立血条；胜利、失败和结算状态仍归 T016。

保持 SRS 已确认的单阶段、1800 生命、270 秒生成、单次冲锋预警至少 0.7 秒、独立血条和无经验掉落规则。T015 不新增结算状态，不改死亡优先于胜利的规则，不增加敌人数量、关卡或依赖。

## 架构方案

评估了三种职责划分：

1. **把 Boss 状态机放进 `EnemySystem`。** 复用最直接，但会让普通追踪系统持有 Boss 专属攻击状态并增加分支。
2. **独立 BossSystem，Boss 实体仍加入共享敌人数组。** 推荐。BossSystem 独占 Boss 追踪/攻击状态；已有碰撞、脉冲枪、轨道刃、击杀事件和敌人绘制继续消费同一敌人数组。`EnemySystem` 跳过 `category === 'boss'`，避免重复移动。
3. **Boss 独立实体数组和独立伤害/瞄准/渲染管线。** 隔离强，但会复制既有碰撞和武器规则，并要求改造多个消费者。

采用方案 2。`BOSS_CONFIG` 提供 Boss 基础实体值和攻击参数；`BossSystem` 每局持有唯一 Boss 引用、是否已生成标记和攻击状态。Boss 继续使用 `Enemy` 实体，配置 `category: 'boss'`、`typeId: 'BOSS-01'`、`expDrop: 0`。生成不使用随机流：从合法地图角点中优先选择离玩家最远且位于视口外的点；这避免改变普通敌人或升级随机序列。现有世界尺寸下至少有合法候选。

## 首轮可调参数（D-036）

| 参数 | 首轮值 | 说明 |
|---|---:|---|
| 生命 | 1800 | SRS 已确认，固定需求值 |
| 半径 | 44 世界像素 | 可调首轮碰撞/占位尺寸 |
| 普通追踪速度 | 60 世界像素/秒 | 可调首轮值 |
| 接触伤害 | 20 | 可调首轮值；冲锋沿用接触伤害与玩家无敌时间规则 |
| 生成视口留白 | 32 世界像素 | Boss 圆形完全位于视口外；地图边界内 |
| 首次攻击等待 | 2.0 秒 | Boss 生成后先追踪，让玩家观察和接近 |
| 冲锋预警 | 0.8 秒 | 高于 SRS 最低 0.7 秒 |
| 冲锋速度 | 420 世界像素/秒 | 固定预警方向，最高位移 252 像素 |
| 冲锋时长 | 0.6 秒 | 到时进入恢复；地图边界钳制位置 |
| 恢复时长 | 0.8 秒 | 结束后回到追踪并启动下次攻击冷却 |
| 后续攻击冷却 | 3.2 秒 | 每轮恢复后生效 |
| 预警通道宽度 | Boss 直径 + 24 像素 | Canvas 中作为半透明警示通道绘制 |

除 1800 HP 和至少 0.7 秒预警外，这些是集中配置的首轮值，可在后续试玩与压力测试中依照记录调优，不改变 Boss 的单阶段与“追踪+蓄力冲锋”行为。

## Boss 状态与攻击行为

- Boss 按有效时间 `>= 270` 秒生成一次。GameWorld 使用当前固定步末端 `clock.elapsedSeconds + deltaSeconds` 判定，因此 269.999 秒仍未出现，跨过 270 秒的该步生成；MENU、PAUSED、LEVEL_UP 和玩家死亡冻结期间不更新 Boss 时间或状态。
- 运行阶段依次为 `approach`、`telegraph`、`charging`、`recovery`。追踪阶段用普通速度直接趋近玩家。首次攻击前等待 2 秒，之后每次恢复完成等待 3.2 秒。
- 进入 `telegraph` 时锁定指向玩家当时位置的归一化方向；Boss 停止移动 0.8 秒。不可变快照携带 Boss 坐标、方向和按地图边界裁剪后的预计终点。Canvas 在该方向显示半透明通道，玩家可通过走位躲避。
- `phaseRemaining` 表示当前阶段距离切换的有效模拟秒数；`chargeDirection` 与 `chargeEnd` 仅在预警/冲锋阶段提供，否则为 `null`。
- 预警结束后，Boss 沿锁定方向以 420 像素/秒移动最多 0.6 秒，位置受世界边界约束；随后静止恢复 0.8 秒并循环。玩家移动不会追踪修正已警告方向。
- Boss 普通追踪与冲锋都由 BossSystem 更新；`EnemySystem` 只更新 `category === 'normal'` 的敌人。Boss 和普通敌人共享接触碰撞/无敌时间逻辑；冲锋不叠加第二笔特殊伤害。

## 数据流、死亡与 HUD

- Boss 出现在 `GameWorld.enemies`，所以 `CollisionSystem`、`WeaponSystem`、`ProjectileSystem`、`OrbitalBladeSystem` 和既有命中伤害自动识别其圆形碰撞与生命值。Boss 不计入普通敌人 100 只上限，也不进入普通波次权重。
- 现有 `GameWorld.#settleEnemyDeaths()` 对 Boss 仍只结算一次击杀，并发出冻结敌人死亡快照；`expDrop: 0` 不会生成经验晶体。BossSystem 保留本局 Boss 引用作为被击败快照，Boss 从活动数组清理后也不会重生。
- GameWorld 提供只读 `getBossSnapshot()`；未到场返回 `null`，到场后返回冻结的 `{ id, typeId, name, x, y, radius, hp, maxHp, alive, phase, phaseRemaining, chargeDirection, chargeEnd }`。快照不暴露内部状态对象。
- Canvas 使用配置尺寸/颜色绘制 Boss 占位方块，预警通道在 Boss 本体之前绘制并裁剪到逻辑视口。正式原创美术与冲锋粒子留给 T017。
- UIManager 只读同一 Boss 快照：未到场或已死亡时隐藏 Boss HUD；存活期间显示“机械暴君 T-01”、当前/最大生命值及语义化进度条。T015 不显示胜负结算。
- `GameWorld.reset()` 清除 Boss 引用、攻击状态和一次性生成标记，但不影响跨局的 UI/状态订阅；下一局从 `opening` 重新开始。

## 更新顺序与错误边界

每个有效 PLAYING 固定步在玩家更新与 Camera 跟随后，先按步末有效时间更新 SpawnSystem 与 BossSystem，再让 EnemySystem 追踪普通敌人，之后执行接触伤害、武器/弹丸/轨道刃伤害和统一死亡结算。Boss 该步生成时不立即移动或发起攻击；既存 Boss 的状态更新发生在接触检测之前。

Boss 配置在构造时验证生命、速度、半径、伤害、生成时间、预警/冲锋/恢复/冷却时长及颜色。数值必须为所需的有限正数（经验可为零）；错误配置快速抛错。无合法角点时使用最远的合法地图角点；构造时校验地图空间能容纳 Boss 直径和安全边距。随机输入不参与 Boss 生成。

## 验收行为

1. 269.999 秒没有 Boss；步末有效时间到达 270 秒生成唯一 Boss，之后即使 Boss 死亡/清理也不重复生成。
2. Boss 初始生命为 1800，半径、速度、接触伤害符合 D-036；生成点在地图内、不与玩家重叠，并在可用视口外位置优先生成。
3. Boss 追踪玩家；预警至少 0.7 秒且方向、预计终点与实际固定方向冲锋一致；冲锋按配置速度/时长运行并受地图边界约束，恢复后再次循环。
4. 玩家武器可以命中 Boss；Boss 接触/冲锋造成既有接触伤害；Boss 死亡只计一次击杀，不掉经验；普通敌人上限/生成曲线不受 Boss 影响。
5. Boss HUD 与 Canvas 预警反映真实只读快照；未生成/死亡时血条隐藏；暂停、升级冻结、玩家死亡冻结和 reset 规则正确。
6. T015 不触发 VICTORY/DEFEAT；胜利条件、失败优先级和终局交互交给 T016。
7. 单元/集成测试、生产构建、差异检查与实际浏览器 Boss 战斗通过；无控制台错误/警告；不安装依赖。

## 需求映射

- SRS §3.1、§3.4：270 秒单次 Boss、1800 HP、追踪与冲锋、死亡无经验 → BOSS_CONFIG、BossSystem、Enemy。
- SRS §3.1、§3.4：至少 0.7 秒冲锋预警和独立血条 → BossSystem 快照、BossRenderer、UIManager。
- FR-012、T015：受伤/死亡幂等、暂停冻结、玩家武器可击败 Boss → 共用 EnemyDamageSystem、死亡结算、BossSystem 与 GameWorld。
- T016 接管 300 秒 Boss 死亡判胜、玩家死亡失败、死亡优先、结算和重开 UI。

## 风险与取舍

- Boss 与普通敌人共享实体数组，保证命中和掉落事件复用；BossSystem 是唯一移动所有者，避免 EnemySystem 与 BossSystem 同步移动造成速度翻倍。
- 预警锁定方向会让玩家走位可以躲避，但 Boss 不会自动转向躲闪玩家；这符合“可辨识危险方向”的 SRS 要求，也能直接单测预警可信度。
- 1800 HP 和非低伤的 Boss 可能导致战斗持续超过 300 秒；SRS 明确允许五分钟后继续战斗，胜负/时间由 T016 负责。T020/T021 完整战局试玩记录耗时与调优依据。
- D-036 新增参数均集中于配置；不引入寻路、Boss 专属投射物、阶段变身或超出 V1 的招式。
