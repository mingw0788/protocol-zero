# T032 经验、补给与武器表现扩展规格

本轮意图：让升级进度随时可见，让城区中继站有明确补充能量的玩法，并扩展拾取选择；修复磁轨炮发射残光与武器脱离的问题。保持 Canvas/Web Audio、固定步、单人局和无依赖边界。

## 决定与首轮可调值

1. 磁轨炮 beam 的短时余辉不是静止世界装饰：射击时记录玩家锚点，展示时把整条已发射线段平移玩家自发射以来的位移，使光效保持连接当前磁轨炮并保留开火方向/线段长度。命中坐标、冷却、伤害完全不变；武器重置清除余辉。
2. XP HUD 同时显示 `当前经验 / 本级门槛` 和有名的进度条。门槛沿用 `getExperienceToNextLevel(level)`（6 + 4×(level−1)）；`player.exp` 仍是升级扣除后本级余量，达到门槛即由现有逻辑暂停选择，不累计成多级显示。
3. 每个城区中继站能量 100。第一次使用仍只需站在半径 64 内累计 2 秒。释放后能量归零且蓄能进度清零；中继圆心 260 范围内每击杀普通敌人/Boss +25 能量，最高 100，四次附近击杀可补满。能量不足时蓄能不增长，当前进度保留；被击杀或电芯补满后，仍须重新站入 2 秒才能再次释放。带 E 的“中继电芯”可在最近中继站 560 范围内一次性补满；没有可作用目标时保留物品。重开重置全部站点到 100。
4. 补给池增加：修复凝胶（拾取即恢复 30，不超上限；满血时留在地面）；EMP 电荷（E 消耗，对玩家周围 220+敌人半径内普通敌人造成 40，Boss 20）；中继电芯（E 补满最近站点）。与诱饵共用单一主动道具槽；主动槽已占用时，新主动道具留在地面。六种道具等权首轮随机，仍来自既有救援站奖励时间线。
5. EMP 只伤害并击杀由既有 EnemyDamageSystem 结算，粒子/冲击表现纯视觉；拾取、使用、收益、能量与枪械遵循暂停冻结和重开清理。音效由语义事件发出，Web Audio 失败不能阻断游戏。

## 验收

- 磁轨线段随玩家平移且长度/方向不变，伤害仍按原路径；reset 余辉消失。
- 初始/升级后 XP 分母正确、进度条和文字跟随真实只读快照，多余经验与暂停选择仍兼容。
- 中继单次输出、附近击杀补能、边界距离、满电上限、低电暂停蓄能、E 电芯距离/库存保留、重开满电。
- 新道具治疗上限/满血保留、主动槽互斥、EMP 圆范围与 Boss 系数、shared kill/exp events 单次结算。
- 菜单说明/HUD 内容、Chrome 与 Edge 实际页面、全量自动化和构建。
