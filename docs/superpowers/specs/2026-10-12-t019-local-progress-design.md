# T019 本地成绩与设置设计

**日期：** 2026-10-12  
**依据：** SRS FR-017/FR-018/NFR-008、SDD §11.8、T016 终局快照、T018 运行期音频设置  
**状态：** 已按连续开发授权实施并验收；交付见 `docs/task-report-T019.md`

## 意图与边界

保存单机用户可见的本机成绩及音效偏好，刷新页面后恢复；存储不可用或数据损坏不能妨碍游戏开局。只保存版本字段、最高击杀、最佳胜利时间、音效开关与音量，不保存位置、生命、升级或任何中途战局。沿用 SRS 玩法和 T016 结算。

## 数据与归属

- `LocalProgressStore` 负责访问 localStorage、JSON 编解码、版本和字段校验。键名集中配置为 `protocol-zero.save`，当前 schema 版本 1。
- 数据记录为 `{ version: 1, highestKillCount, bestVictorySeconds, soundEnabled, soundVolume }`。击杀为非负安全整数；最佳胜利秒数为 `null` 或有限非负秒数；音效开关为布尔值；音量为 `[0,1]`。
- `LocalProgressSystem` 在 Game 创建时读取一次并提供冻结快照；设置变化时立即安全写入；收到已结算胜败时更新最高击杀，胜利局才用更短的有效时长更新最佳通关时间。败局不改变最佳通关成绩。
- GameWorld 的冻结运行结果事件由 Game 消费一次；Game 复用现有终局快照，仍由运行时更新的规则决定结算，不由存档影响。
- 缺键、损坏 JSON、未知版本、字段越界、localStorage 属性访问/读取/写入抛错时回退默认内存状态。写入失败不回滚当前页面内的设置或成绩，也不抛出到游戏逻辑。
- 主菜单显示“最高击杀”与“最佳通关”；未有胜利记录时显示“尚无”。重开/返回菜单不清除保存数据。默认声音开、音量 65%。
- D-016 定义为：任何已结算局都参与最高击杀；仅胜利局参与最佳通关，数值越低越好。沿用 T016 真实 `elapsedSeconds`，不定义新的胜负条件。

## 验收

- 存档单测覆盖缺失、往返序列化、无效 JSON/字段/版本、本地存储 getter/read/write 异常及读取结果冻结。
- ProgressSystem 覆盖最高击杀比较、失败局不更改最佳时间、胜利时间取最小、有效音频设置更新、失败写入不影响内存状态。
- Game/UI 集成验证首次加载偏好、真实终局只记录一次、菜单成绩文本、设置立即保存、重开/返回保留且不保存战局中间状态。
- 全套测试、生产构建、`git diff --check` 通过；Chromium 刷新验证偏好/记录保留及不受损坏存档影响；不新增依赖。

## 实施解释

此功能只记录设备当前站点 origin 下的本机数据，不同步云端或跨浏览器。localStorage 失败时仅提供当前页面内存退化；写入结果明确反映为不可持久化但不阻断单局。
