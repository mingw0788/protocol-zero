# T009 设计规格：经验晶体掉落与拾取

## 审批状态

2026-10-12，用户已逐节通过本设计的死亡事件数据流、晶体生命周期、GameWorld 接线、图层和验证范围，并确认 D-017 与 D-026。本文为书面规格，等待用户审阅；审阅通过前不编写实施计划或游戏代码。

## 1. 目标与范围

完成 SRS FR-008 的经验掉落与拾取闭环：敌人死亡时依据配置生成晶体，玩家接触后获得经验，HUD 通过现有真实状态快照显示经验。本任务只改变经验数值，不计算升级阈值、不切换 `LEVEL_UP`、不显示升级卡片；这些由 T010/T011 实现。

范围包括 `ExperienceCrystal`、`ExperienceSystem`、`GameWorld` 集成、只读 Canvas 占位绘制和相应单元/集成/浏览器验证。不新增依赖，不引入磁吸、掉落合并、背包或其他成长机制。正式晶体美术留给 T017。

## 2. 已确认玩法参数

- 一条正经验值的敌人死亡通知生成一枚晶体；`expValue` 等于死亡快照的 `expDrop`，位置等于快照坐标。`expDrop` 为 0 时不生成晶体。EN-01 当前掉落 1 点；未来敌人继续使用各自配置值。
- 拾取采用圆形接触判定：存活玩家与晶体中心距满足 `distance <= player.radius + pickupRadius` 时立即拾取。首轮 `pickupRadius` 为 12 世界像素；不做磁吸。
- 晶体有效寿命为 120 个有效战局秒，到期静默清理。暂停和玩家死亡冻结期间不推进寿命。恰好在寿命边界与玩家重叠时，优先拾取，然后才进行过期清理。
- 占位外观为可配置的琥珀色 8×8 方块；正式素材、动画和特效不属于 T009。
- 晶体值直接增加 `player.exp`。HUD 沿用 `GameWorld.getHudSnapshot()` 的已有 `experience` 字段。

上述数值是可配置的首轮平衡值；试玩后如需调整，记录原因并同步需求与配置。

配置由只读 `EXPERIENCE_CRYSTAL_CONFIG` 集中持有：`pickupRadius: 12`、`lifetimeSeconds: 120`、`renderSize: 8` 和琥珀色 `color`。逻辑规则读取同一份配置，不在实体更新或绘制逻辑中复制参数。

## 3. 架构与职责

### 3.1 ExperienceCrystal

运行时实体字段：

```text
id, x, y, expValue, pickupRadius, remainingLifetime, active
```

构造时校验非空 ID、有限坐标、正有限经验值、正有限拾取半径和寿命。实体不访问 DOM，不判断等级阈值，不直接操作 HUD。

### 3.2 ExperienceSystem

- `GameWorld` 建立一个 `experienceCrystals` 数组，并把同一数组、Player 和自身死亡事件接口交给单个 `ExperienceSystem`。
- 系统构造时只调用一次 `subscribeEnemyDeath(listener)`；监听关系跨 `reset()` 保留。它复制冻结的死亡快照字段，不修改快照或敌人。
- 收到 `expDrop > 0` 的通知时，在快照坐标创建一枚 `ExperienceCrystal`。T008 的 `deathProcessed` 与一次性死亡通知是掉落幂等边界，T009 不维护跨局永久死亡 ID 集合。
- 每个有效模拟步检测玩家/晶体圆形相交。拾取时先设 `active = false`，再把 `expValue` 加到 `player.exp`；失效实体在原数组内清理，保持共享数组引用稳定。
- 玩家已死亡时不拾取。晶体在达到寿命边界的同一步先进行拾取判定，再扣除寿命并清理过期实体。
- `reset()` 将旧晶体标记失效并清空数组，不取消死亡事件订阅、不回放历史事件；晶体 ID 序号在系统生命周期内持续递增。
- 系统拒绝负数或非有限的 `deltaSeconds`；零步长不改变经验、寿命或实体状态。

### 3.3 GameWorld 固定步接线

保留 T007 接触伤害、T008 投射物伤害和死亡结算顺序。每个有效固定步的相关顺序为：

1. 更新玩家、敌人和接触伤害；
2. 发射并推进脉冲弹丸；
3. 对投射物造成的死亡设置 `deathProcessed`，同步发布冻结死亡快照，再清理死亡敌人；
4. 调用 `ExperienceSystem.update(deltaSeconds)`，处理新旧晶体拾取与寿命；存活玩家可在刚生成晶体的同一步拾取；
5. 推进战局时钟和模拟步计数，完成原有玩家死亡事件与冻结处理。

`GameWorld.update()` 在非 `PLAYING` 状态或玩家死亡冻结后不调用系统，所以暂停及冻结期间经验晶体寿命停止。玩家死亡的固定步仍按原规则完成；已死亡玩家不会拾取该步新生成的晶体。`GameWorld.reset()` 清空晶体，同时重置玩家经验为 SRS 初值 0。

## 4. 绘制与 HUD

- 新增只读 `ExperienceCrystalRenderer`，只绘制 `active` 晶体；按 Camera 世界到屏幕坐标转换、逻辑视口裁剪和视口外剔除规则绘制占位方块。
- Canvas 图层为：地图 → 经验晶体 → 弹丸 → 敌人 → 玩家。渲染器不变更实体、经验或寿命。
- `Game` 将 `GameWorld.experienceCrystals` 交给 Canvas 渲染端。HUD DOM 不新增经验数据源、不直接修改 Player；现有快照在下一次渲染时自然显示经验变化。

## 5. 错误处理与性能

- 配置和实体坐标/数值使用有限值验证；非法 `deltaSeconds` 抛 `RangeError`，无效实体参数在构造时抛出类型或范围错误。
- 对零经验死亡通知不创建实体；T008 已验证的敌人死亡事件契约负责一次性发放。拾取和过期都先置失效再原位移除，避免重复奖励与数组替换。
- 生命周期由固定模拟时间驱动，暂停、失焦自动暂停、菜单和死亡冻结均不消耗寿命。
- 120 秒寿命使当前 T006 每秒至多尝试生成一个 EN-01 的晶体保留窗口有界。T014 波次参数变更后，T020 需验证高密度下晶体数量与遍历成本；T009 不提前引入对象池或空间索引。

## 6. 验收与测试范围

### 单元与集成测试

- `ExperienceCrystal` 配置、坐标、经验值、拾取半径、寿命和 ID 校验。
- 正经验死亡产生一枚正确坐标/数值的晶体；零经验不掉落；死亡多次结算不会增加重复晶体。
- 拾取半径内、边界相切和范围外行为；只给存活玩家加经验；重复更新不会重复加经验。
- 120 秒到期清理、零步长、非法步长；暂停、死亡冻结不推进寿命。
- T008 死亡通知到晶体、拾取到 `player.exp` 与 HUD 快照的集成；重开清空晶体但保留订阅并允许下一局继续掉落。
- Canvas 只读绘制、图层顺序、视口裁剪和不可见晶体跳过。

### 浏览器验收

从标题菜单开始，移动 ZERO 靠近被脉冲枪击杀的 EN-01，观察单枚琥珀色晶体在接触后消失且 HUD 经验增加 1；远离晶体时经验不变。暂停一段时间后确认晶体仍可拾取；返回菜单并开始新局后确认旧晶体不再存在。检查页面与浏览器控制台无新增错误/警告。

## 7. 非目标与后续任务

- T009 不实现 `6 + 4 × (L - 1)` 升级阈值、经验溢出、连续升级队列、升级 UI 或经验加成；均留给 T010/T011。
- 不增加吸附、自动寻路、合并掉落、额外掉落品或经验声音；不改变敌人配置掉落值。
- 不制作正式晶体素材、发光动画或拾取特效；留给 T017。
- 不调整 T008 的伤害、射速、敌人死亡事件或战斗时序。
