# T035 双主动道具槽设计

日期：2026-10-14。状态：按用户“根据上述方案执行计划”的授权实施；首轮交互细节记录为提案默认值。

## 目标

在不改各道具效果的条件下，将诱饵、EMP、中继电芯从单槽升级为两个独立携带槽，并让玩家能看见槽位状态、互换地面道具。

## 输入与交互

- E 使用第 1 槽；Q 使用第 2 槽。每次物理按下只排入一次操作，按住/键盘 repeat 不连续使用。
- F 与 E/Q 同一模拟步同时触发时只执行 F，丢弃该步道具使用请求，防止新换入道具被意外立刻使用。
- 当前选中槽默认为第 1 槽；E/Q 选中对应槽，即使为空也能看出选择焦点。
- C 在两槽之间切换高亮，不使用物品；用于保留现有道具的交换。补充此键是为填补路线草案缺少独立选槽动作的交互缺口。
- 自动拾取主动道具时，填入第一个空槽；两槽已满则地面道具保留。
- F 与地面主动道具交互距离为 64 世界像素（中心距）。多个道具等距时按稳定 pickup ID 升序选择。
- 选中槽为空时，F 将近处道具放入该槽并移除地面对象；选中槽有道具时，双方原子交换：地面对象变成旧槽道具并重置为完整 60 秒寿命，新道具进入槽。交换前后实体数量不变。
- 无近处道具、选中槽无效/为空时均保留状态并显示原因；中继电芯在无法补能时仍保留，不清空对应槽。
- reset 清空两槽、选中状态、道具交互提示和输入 pending；切换暂停/升级/失焦清掉尚未处理的按键，不消耗道具。

## 状态与界面

- SupplySystem 拥有 `[slot0, slot1]` 和 `selectedSlot`；快照冻结 `activeItems`、`selectedSlot`、附近可交换道具，并暂留 `activeItem` 只读别名（等于 slot0）以兼容内部旧消费者。
- InputController 只报告一次性按键请求，不直接操控库存。GameWorld 每个固定步最多执行一次槽交换或一次槽使用。
- HUD 显示 E/Q 两槽名、选中态和 F 交换提示；附近有可交换道具时显示名称。不新增鼠标交互，不加 HUD 常驻按钮。
- 帮助文案同步说明 E/Q/F；暂停冻结，重开清空。
- Pickup 名称沿用 SUPPLY_NAMES；各道具已存在效果和大小写以 T032/T033 为准。

## 验收

- 两槽顺序填充；第三件主动道具保留地面；E 与 Q 使用正确物品；空槽切换不会影响另一槽。
- 交换仅选择范围内最近道具，等距稳定；有物时原子互换且实体数、拾取寿命符合规则；空槽交换拾取成功。
- 距离边界为 64，失败保留；电芯作用失败不消耗；同时按下 F 与 E/Q 不误用。
- 重复键、按住、失焦/暂停、LEVEL_UP、重开都无重复使用/残留输入。
- HUD/帮助在桌面和窄视口下可读；Chrome/Edge 实际键盘检查，全量自动化和生产构建通过。
