# T017 原创像素视觉、动画与界面打磨设计

**日期：** 2026-10-12  
**依据：** SRS §2.1/§5/FR-016/NFR-010、SDD §7/§10、现有 T005–T016 Canvas 与 DOM 接口  
**状态：** 已实施并完成验收；交付报告见 `docs/task-report-T017.md`

## 意图与边界

把目前的纯色方块占位提升为可辨识且统一的赛博朋克像素风：ZERO、三类普通敌人与 T-01 有不同剪影；移动/待机、受击闪烁、敌人死亡、射击/命中、经验晶体和 Boss 预警提供清楚的短动画/反馈；地图和 DOM HUD/菜单保持阅读清晰。不得改动移动、伤害、武器、升级、敌人属性或胜败规则。无需外部素材：本项目当前没有素材目录或加载层，采用小型内嵌像素矩阵和 Canvas 绘图，避免加载失败及新增依赖。

## 绘制与时钟

- `spritePatterns.js` 保存冻结的颜色索引矩阵；`PixelSpriteRenderer`/共享绘制辅助按逻辑世界单位绘制最近邻方块，按类型选择剪影并将尺寸限制在既有碰撞直径内。未知 typeId 使用中性 fallback。
- PlayerSystem/Player 只保存 `moving` 与最后朝向供表现读取，不改变速度/位置公式；基于 GameClock 有效时间驱动两帧步态和微小待机变化。受击期间按固定 0.08 秒相位闪烁；死亡/暂停不推进。
- 敌人以稳定实体 ID 相位加有效时间做轻微呼吸/摆动；不得更改坐标或碰撞。晶体使用像素菱形与高光；弹丸和轨道刃增加紧凑亮核；Boss 预警以时钟驱动亮度/间隔反馈，通道仍低于 Boss 本体且不遮蔽其方向。

## 视觉效果系统

- 新增 bounded `ParticleSystem`：接收既有冻结 enemy-death 和 player-death 事件，以及 GameWorld 已结算的玩家受伤结果；无 Math.random，不改变随机流。粒子使用规则方向、小尺寸、有限寿命/速度，按固定步更新，超上限丢弃最旧项；默认上限 320、寿命 0.45 秒，集中配置。
- `GameWorld.getVisualEffectsSnapshot()` 返回只读活动粒子数据。效果先在实体下层/敌人上层绘制，短促且不遮盖玩家、Boss 预警或 HUD。暂停、LEVEL_UP、终局冻结均不更新；reset 清空效果。
- 不对每颗子弹/每次轨道刃接触产生粒子，避免密集战斗放大绘制量；仅在已结算敌人死亡和实际玩家受伤时触发。

## 场景与 UI

- MapRenderer 增加少量按固定地图坐标铺排的地砖边线、实验室地面标记和稀疏电路短线；不新增阻挡物、危险区或碰撞。
- CSS 统一现有蓝黑底、青蓝玩家、红橙敌人、紫色奖励、金色 Boss 层级；强化状态对比、按钮反馈、文本间距与小屏适配。保留可访问 DOM、语义标签和对比度。

## 验证

自动化覆盖每种类型的矩阵映射/回退、尺寸和裁剪、有效时钟动画状态、受击闪烁、粒子生成/速度/寿命/上限/暂停和 reset、Boss 预警可读性及地图视觉无游戏状态副作用；额外覆盖终局冻结前死亡粒子的初始展开及配置副本隔离。全套测试 44 文件 / 361 项通过，Vite 生产构建 56 模块通过。Windows Chromium 154 检查 MENU、PLAYING（敌种、Boss、粒子）、PAUSED 与 640×360 终局 UI；控制台错误/警告 0/0，检查到的资源均来自本地开发源，无新增依赖。视觉状态通过有效模拟时钟输入；不使用渲染帧随机值。完整证据见 `docs/task-report-T017.md`。
