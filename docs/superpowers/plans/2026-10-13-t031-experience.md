# T031 Experience Implementation Plan

> 执行方式：superpowers:executing-plans，沿用 Native；按用户持续授权直接实施。

**Goal:** 可读的战斗反馈、独立音色与可互动城区。

**Architecture:** GameWorld 推进表现计时并转发语义音事件；RelaySystem 持有三个有限状态站点，复用 EnemyDamageSystem；渲染读取状态。

**Tech Stack:** 既有 JavaScript / Canvas / Web Audio / Vitest，无新依赖。

**Spec:** `docs/superpowers/specs/2026-10-13-t031-experience-design.md`。
