# Protocol Zero 下一轮玩法与功能扩展计划

日期：2026-10-14。状态：**路线经用户授权开始执行；T034–T038 已完成，T039–T045 待执行。**

本文件先按用户要求整理为计划，随后用户明确要求“根据上述方案执行计划”。本文件是分批产品与开发路线图，不是可直接逐项执行的详细代码实施规格。新增玩法的首轮值属于执行阶段设计提案；落实每项时会记录规格、接口与数值，并同步 SRS、SDD 和决策记录，不将计划草案误写成用户逐参数确认。

## 1. 目标与现状

目标：让每一局在路线、交战方式、升级组合和奖励选择上产生变化，同时保留容易上手、自动攻击、短局生存的体验。

依据：README、requirements、architecture、development-plan、task-status、decisions、T033 交付报告及当前地图/升级/世界/存档代码。

当前已有：2 张地图、4 种武器、8 种道具、冲刺、护盾、经验条、升级重抽、探索终端、中继补能、雷达和单 Boss。磁轨炮余辉跟随与经验进度已由 T032 交付，不再当成新增项目。

主要缺口：普通敌人行为差异有限；地图机制多为驻足领取；构筑缺少后段变化；主动道具共用单槽；结算对流派成效解释较少。人工自然完整战局和整帧性能证据仍需补齐，不能用既有自动模拟代替。

## 2. 路线选择

| 路线 | 收益 | 代价 |
|---|---|---|
| 大量新增武器、地图和数值升级 | 内容数量提升快 | 同质化、候选池稀释、平衡工作增长 |
| 战术与构筑联动（推荐） | 现有冲刺、道具、中继和武器能互相配合，单局差异更明显 | 需统一伤害、事件和奖励规则 |
| 长期养成与长局优先 | 增加长期目标 | 容易变成重复刷数值，延后核心战斗改善 |

采用第二条作为主线，长期内容放在核心体验稳定之后。默认五分钟模式保留；环境危机、新 Boss 和长局作为明确可选的扩展内容。

## 3. 第一批：战场变化与更好的操作

### A. 动态事件与环境互动

- 增加三类可选事件：防守数据链路、追击运输无人机、清除精英夺取物资箱。
- 建议每局 60 秒和 165 秒各尝试触发一次，240 秒后不再开启，给最终 Boss 留出空间。同一时间最多一个事件，失败只失去奖励。
- 数据链路要求在区域内累计防守 15 秒；离开暂停进度，事件总期限 35 秒。运输无人机沿预设开放路线移动，玩家靠近累计解锁，避免额外瞄准操作。
- 事件位置从当前地图的合法锚点抽取；不占据出生点、终端或中继中心，不与危险区重叠。没有安全锚点则跳过，不强制生成。
- 增加可击毁的电容桶：自动选靶仍优先敌人，附近没有敌人时才攻击桶；爆炸伤害敌人、不给玩家造成误伤，连锁次数设上限，桶不产生普通击杀或经验。
- 增加周期性电弧区域：先预警再伤害，建议预警至少 1 秒；区域关闭后可以安全穿过。优先加入新地图，旧地图保持现有规则。
- HUD 只追踪一个主要目标，其他目标在雷达显示；可循环切换追踪对象，避免多个方向箭头叠在一起。

### B. 战术敌人

| 敌人 | 玩法作用 | 可辨识的应对方法 |
|---|---|---|
| 狙击哨兵 | 迫使玩家横向闪避 | 射击前画瞄准线，锁定后不再追踪，预警至少 0.9 秒 |
| 自爆爬行器 | 让敌群走位产生变化 | 接近后停步倒计时，警示圈至少 1 秒；提前击杀取消爆炸 |
| 干扰精英 | 提供优先击杀目标 | 有限范围提高附近普通敌人移速，光环清晰；自身不受益、光环不叠加 |

普通新增敌人占用现有 100 敌上限，替换一部分旧生成份额；精英也计入上限，场上最多一个。新敌从第二分钟逐步引入，不在开场同时出现。诱饵对新普通敌人有效，但已经锁定的射击/爆炸预警不重新瞄准。

敌方弹丸有独立数量与寿命上限，不能与玩家弹丸共用阵营判断。接触、弹丸、爆炸和环境伤害统一经过护盾/无敌/死亡管线；扩展模式建议冲刺免疫这四类伤害，禁止各系统各扣一次生命。

### C. 道具操作与信息反馈

- 两个主动道具槽，E/Q 各使用一个；现有即时道具自动拾取，主动道具进入空槽。
- 两槽都满时，新道具留在地上；靠近显示名称，按 F 交换最近一次选中槽，交换操作不同时使用道具。选择距离相同时按稳定 ID 决定。
- 新增使用失败提示：无可用目标、距离不足、槽位为空；失败不吞道具。
- 中继展示能量、补能方式和当前可用作用。增加两种站点专长：医疗中继治疗，火力中继短时增强攻击；同一次满能量只激活所属专长一次，能量来源仍沿用附近击杀/电芯。
- 暂停页展示本局武器、升级、临时增益剩余时间；结算显示各武器有效伤害、击杀贡献、探索和事件完成情况。
- 加入可关闭伤害数字、减少闪光/震动、危险提示强化选项；颜色与形状共同区分危险和奖励。

## 4. 第二批：武器流派、道具与地图

### A. 两种新武器，形成六武器内容池

| 武器 | 核心用途 | 约束 |
|---|---|---|
| 冷凝喷射器 | 自动朝近敌喷射短程扇形，减速控场 | 减速取最强值，不累乘；Boss 减速较弱且免冻结 |
| 蜂群无人机 | 随玩家移动，周期攻击周边敌人 | 无人机及弹丸数量封顶，无目标时归位；不承担导航寻路 |

两武器都需要可见机体、独立开火表现和可辨识音色。首轮具体伤害/频率以现有四武器的实际输出数据为参照，在详细设计阶段给出，不提前承诺平衡。

### B. 四种现有武器进化

| 进化 | 建议条件 | 行为变化 |
|---|---|---|
| 裂隙脉冲 | 多重脉冲满级 + 火力强化至少 3 级 | 命中后产生一次有限分裂，分裂弹不能再次分裂 |
| 磁暴轨道 | 轨道刃满级 + 纳米装甲至少 2 级 | 周期外扩扫击，保持逐目标命中间隔 |
| 雷暴网络 | 弧光线圈满级 + 回收扫描器至少 1 层 | 连锁末端产生一次范围电爆，禁止二次连锁触发 |
| 裂城磁轨 | 磁轨炮满级 + 火力强化至少 3 级 | 贯穿射击附带短寿命伤害轨迹，每目标限频 |

条件达成后，在下一次升级中保证出现一个合法进化选项；选择消耗当次升级，不额外吞道具或被动等级。进化不重复出现，重抽不能抹掉所有已满足条件的进化机会。前两批先交付两种进化，再交付剩余两种，避免同时调整六武器平衡。

扩展模式增加最多 3 个武器栏位（含开局脉冲枪），让选武器成为取舍；现有模式保留已有装备规则。栏位满时排除新武器解锁卡，但允许强化和进化。升级池采用“有合法强化时至少一个已持有武器强化选项”的保底，不让六武器内容稀释成长。游戏内提前清楚展示栏位和进化条件。

### C. 四种新道具

- 冷凝炸弹：主动范围减速，提供脱离包围的窗口。
- 自动炮台：主动放置，有限寿命、有限数量，复用伤害结算。
- 纳米维修场：主动放置小范围持续恢复区，满血不累积治疗；被迫离开意味着放弃后续收益。
- 协议增幅器：即时获取一次短期中继增效，下一次成功激活中继消费；已有未消费增幅时地面保留。

新增后道具种类由 8 增至 12。通过事件类别分配奖励池，例如防守更容易获得防御/维修道具，避免把全部道具塞进单一等概率池。旧击杀补给的基础恢复来源保留。

### D. 第三张地图：失控能源枢纽

采用开放战场与预设区域组合，不引入建筑阻挡和复杂寻路。复用当前世界尺寸与摄像机边界，增加中央反应堆、三片外围作业区、环形安全通道。

- 三条电弧走廊轮流通电，任何时刻至少留一条明确安全通道。
- 完成外围终端可在本局永久关闭相邻走廊，并获得奖励，形成“先探索降低风险”与“直接打怪成长”的选择。
- 中央装置完成充能可释放一次范围冲击；敌人击杀、环境装置和道具之间形成联系。
- 每局从经检查的 3 套锚点布局中选择一套，地标/终端/事件同步使用该布局；不使用未经可达性验证的任意随机坐标。

## 5. 第三批：重复游玩与完整体验

- 新地图 Boss“电网监护者”：使用已有电弧预警语言，分两阶段，第二阶段增加攻击组合；270 秒出现，仍以达到 300 秒且 Boss 死亡获胜。切阶段不能瞬间伤害玩家，不刷新完整生命。
- 开局协议三选一：突击（火力收益与防御代价）、回收（探索收益与攻击代价）、守卫（防御收益与机动代价）。在完整平衡设计中固定数值，菜单显示收益与代价，允许选标准配置。
- 可选挑战：高压敌潮、物资稀缺、精英增援。每局先只允许一个词条，清楚说明改变的规则，成绩按地图/模式/词条分别记录。
- 胜利后提供可选无尽模式。先保存本次标准胜利，再进入独立加时成绩；后续死亡不能把已获得的标准胜利改为失败。
- 本地图鉴与成就：发现敌人、解锁进化、完成事件、地图挑战；优先奖励外观与横向开局选择，不添加无限永久攻击力。
- 版本化本地存档迁移，保留旧成绩和音量；导出/导入仅支持校验后的有限 JSON，不保存进行中战局。
- 音频增加独立音乐/音效音量、低强度原创循环背景音与战斗层次；重要危险声优先，静音/低特效仍完整表达规则。

## 7. 架构约束与关键风险

1. GameWorld 继续编排，事件、危险区、统计各自持有状态，不继续把所有规则加入同一个世界类。仅抽取本批需要的边界，不做全局 ECS 重写。
2. 伤害需带来源/阵营，统计仅记录实际扣减生命或护盾的数值，致死过量不算有效输出；所有死亡、经验、补给和成就只结算一次。环境物件不计敌人击杀。
3. 随机事件、升级、生成使用隔离随机流；复现报告记录种子及运行配置。关闭表现选项不能改变战斗随机序列。
4. 探索奖励、事件奖励与磁铁经验都进入现有升级队列，不另起竞争弹窗；新增奖励选择要排队，明确先后顺序。
5. 暂停、升级、失焦冻结全部新增计时；重开清理道具槽、无人机、危险区、事件、进化、统计及 Boss 阶段，保留设置和历史。
6. 新危险/敌弹加入后统一明确冲刺和护盾行为；不能让新伤害绕过保护造成无法理解的死亡。
7. 武器进化、弹丸、爆炸、炮台必须限制实体数和递归触发次数，视觉效果过多时先降表现，不能静默漏算伤害。
8. 存档升级采用显式迁移和校验；存储失败允许继续玩并提示未保存。未知版本不覆盖已有原始存档。
9. UI 不新增一整排永久仪表；生命/经验/危险优先，次要统计放暂停和结算，事件只显示当前追踪项。
10. 默认旧地图与五分钟成绩不混入新模式；所有新规则有明确模式范围，防止旧成绩失去可比性。

## 8. 验收与发布门槛

| 类别 | 必须检查的结果 |
|---|---|
| 规则 | 同帧多伤害、冲刺、护盾、死亡优先、连锁上限、升级队列与奖励幂等正确 |
| 道具 | 两槽满/空、距离边界、无目标、交换与使用同时输入均不丢失或重复发放 |
| 状态 | 在事件完成、Boss 切阶段、进化与无尽入口暂停/失焦/重开，不产生残留和重复结算 |
| 成长 | 武器栏满、升级候选不足、全满级、重抽与进化保底无死路；五分钟内有合理机会达成进化 |
| 存档 | 旧版本迁移、损坏/超大导入、禁用存储、标准胜利后无尽失败均正确 |
| 实战 | 每地图至少两个不同武器流派自然试玩，记录首次升级、首次进化、受伤来源、完成目标和结局；不得以作弊数值通关替代 |
| 体验 | 640×360 与常用桌面尺寸能读清危险和操作；低特效/静音模式不丢关键信息；主观试听单独记录 |
| 性能 | 100 普通敌人加 Boss、六武器内容中的最重合法组合、满量敌弹/危险区/道具的完整帧测量；记录机器、浏览器、P95 和内存趋势 |
| 稳定性 | Chrome/Edge 完整标准战局、无尽 20 分钟压力局、连续重开 10 次无异常累积 |

60 FPS 仍是目标，不能只用 Canvas 绘制时间作结论。未达性能目标时优先减少同时视觉效果和危险源，再评估生成强度，不直接放大敌人数量。前两批分别完成相关子集验收；T045 才汇总全部证据。

发布准备在功能及质量门槛通过后单独安排，计划完成不等于功能完成或线上更新。
