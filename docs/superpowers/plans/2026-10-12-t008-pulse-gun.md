# T008 脉冲枪自动攻击实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在有效 PLAYING 模拟步中实现自动选靶、脉冲弹丸、敌人伤害和一次性击杀结算。

**Architecture:** `WeaponSystem` 从玩家每局武器状态读取冷却并创建 `Projectile`；`ProjectileSystem` 用线段圆形检测推进弹丸并调用 `EnemyDamageSystem`。`GameWorld` 继续拥有模拟顺序、击杀计数和不可变死亡通知，Canvas renderer 只读绘制弹丸。

**Tech Stack:** 原生 JavaScript ES modules、Canvas 2D、Vitest 5、Vite 8；不增加依赖。

**Spec:** `docs/superpowers/specs/2026-10-12-t008-pulse-gun-design.md`

## Global Constraints

- 仅有效 PLAYING 步推进战斗；沿用 1/60 秒固定步和单帧最多 5 步补算。
- 脉冲枪伤害为 20，射速为 1.25 发/秒（0.8 秒间隔），射程 640 世界像素，弹丸速度 500 世界像素/秒、半径 4、寿命 1.28 秒。
- 以玩家/敌人中心距离选最近合法目标；首次有目标且武器可用时立即发射，无目标时冷却仍倒计时。
- 弹丸锁定方向直线飞行；线段圆形检测命中沿途最近敌人，命中即消失、不穿透。
- GameWorld 在清理敌人前设置 `deathProcessed`、只增加一次击杀并发送冻结 `{ enemyId, typeId, x, y, expDrop }` 通知。
- reset 清空弹丸与玩家每局冷却，保留死亡订阅且不重放旧事件。
- 不创建经验晶体或特效，不改既定玩法，不安装依赖。

## Review Focus

- 非有限/非正武器配置、非法更新 delta 或被外部污染的目标坐标：应尽早报错或安全忽略；由 Task 2、3、4 的构造/配置/更新测试覆盖。
- 玩家与目标同坐标：选靶和归一化不能产生 NaN，且起点重叠可立即命中；由 Task 3、4 的重合测试覆盖。
- 等距目标、等交点敌人和射程边界：每次选择必须确定且符合包含边界规则；由 Task 3、4 的顺序与边界测试覆盖。
- 单步 delta 大于弹丸剩余寿命：只检测有效寿命内轨迹，不能过期后命中；由 Task 4 的大步长测试覆盖。
- 敌人死亡、清理、reset 与订阅取消交错：击杀/通知只发生一次，监听关系跨局保留且不重放；由 Task 5 的生命周期测试覆盖。
