## 实现内容

| 功能 | 当前规则 |
|---|---|
| 相位冲刺 | Shift；沿移动方向，静止时沿朝向；0.18 秒、3 倍移速、4 秒冷却；冲刺期间免接触伤害，受地图边界限制 |
| 相位护盾 | 拾取补至 30 点吸收量；溢出才扣生命；满盾保留道具 |
| 回收磁铁 | 立即回收全地图现有有效经验晶体；正常处理连续升级 |
| 击杀补给 | 两地图每 15 普通击杀依次掉落凝胶/护盾/磁铁/过载；Boss 不计入；拾取物保留 60 秒，总量上限 24 |
| 地图终端 | 两地图各 3 个；连续站入 2.5 秒，离开清空上传进度；每个奖励 6 XP 与指定道具；全收集追加 12 XP 和一次重抽 |
| 升级重抽 | 每局初始 2 次；R 或按钮重抽，保证至少一个新选项；无替代时禁用，不消耗次数 |
| 操作与反馈 | 1/2/3 选升级；冲刺冷却、护盾、掉落进度、目标导航、拾取提示、低血量提示、探索/补给结算统计 |
| 雷达与画面 | 小地图显示玩家/视口/终端/中继/补给；终端上传环、护盾轮廓、冲刺拖影、附近道具名称与新合成提示音 |

详细参数见 `docs/superpowers/specs/2026-10-13-t033-tactical-exploration-design.md`。参数是自主设计的首轮值，不声称用户逐个确认。
