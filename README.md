# Protocol Zero · 零号协议：失控之城

**V1.0.0** · Windows 桌面浏览器单人像素风生存游戏

ZERO 在失控的科技实验室中自动攻击感染机械。移动躲避敌群，收集经验并选择升级，在 4:30 击败机械暴君 T-01；到达 5:00 且 Boss 已被击败后获胜。Boss 未死时战斗会继续，玩家生命归零则失败。

## 运行要求

- Windows 11 桌面版 Chrome 或 Microsoft Edge。已实际验证 Chrome 154.0.8037.98 与 Edge 152.0.4191.53；其他浏览器和操作系统尚未验证。
- Node.js `^22.12.0 || ^24.0.0 || >=26.0.0` 与 npm 11.13.0。

## 安装和启动

```sh
npm ci
npm run dev
```

打开开发服务器显示的本机网址。命令行工具和测试：

```sh
npm test          # 运行 Vitest 测试
npm run build     # 生成静态生产文件到 dist/
npm run preview   # 本机预览 dist/ 生产构建
```

构建产物可部署到静态文件托管服务，无需游戏后端、账号或游戏 API。`dist/` 不提交到源码仓库。

## 操作

| 输入 | 操作 |
|---|---|
| W/A/S/D 或方向键 | 八方向移动；斜向速度已归一化 |
| 自动 | 脉冲枪自动攻击射程内最近敌人；轨道刃解锁后自动环绕攻击 |
| Esc | 在战斗与暂停之间切换；升级选择期间不能跳过 |
| 鼠标 | 开始、帮助、音效设置、选择升级，以及操作暂停/结算菜单 |

暂停菜单的“返回主菜单”会先确认；取消后仍保持暂停。切换到后台会自动暂停，回到游戏页面后需手动继续。升级面板出现时战斗冻结，选择一项后继续。

## V1 内容与记录

- ZERO、有限科技实验室地图、三种普通敌人、脉冲枪与可升级的轨道刃、六类升级，以及单阶段 Boss T-01。
- 五分钟挑战、暂停、升级选择、胜负结算、重开与返回主菜单。
- 原创代码像素图案、Canvas 动画与 Web Audio 合成短音效；V1 不含背景音乐。
- 浏览器本地保存最高击杀、最快胜利用时、静音与音量。刷新或重新开始不会恢复进行中的战局；记录只在当前浏览器配置中，不同步到云端。

## 验证范围与已知限制

- T020 自动化回归：50 个测试文件、395 项通过；Vite 构建转换 60 个模块。
- Windows 11 上使用 Playwright 无头浏览器验证 Chrome 154 与 Edge 152 的菜单、战斗 HUD、暂停、升级选择 UI、重开和本地记录。Playwright 事件模拟通过，但真实操作系统级切换后台标签页的验证仍有限。
- T020 的一次自然键盘战局在 00:32、16 次击杀时失败，未进入第一次升级；因此自然完整五分钟战局与 Boss 平衡仍未验证。另有受控流程验证胜负边界，但它不代表自然通关。
- 合成高密度场景中，真实 Canvas 绘制调用的 P95 为 Chrome 5.6 ms、Edge 4.3 ms。该基准不含整帧模拟、DOM 更新、浏览器合成或 GPU 成本，不构成整局恒定 60 FPS 的承诺。
- 游戏使用浏览器存储；清除站点数据或更换浏览器配置会移除本地成绩和设置。

详细验收证据及限制见 [`docs/task-report-T020.md`](docs/task-report-T020.md) 和发布记录 [`docs/task-report-T021.md`](docs/task-report-T021.md)。

## 素材与许可

游戏图像由仓库内原创代码像素矩阵绘制，音效由 Web Audio API 合成；没有随游戏分发的第三方图像或声音文件。当前仓库未授予通用开源许可证。若需复用或再发布源码，请先取得项目所有者许可。
