# Protocol Zero · 零号协议：失控之城

**V1.0.0 基线 + T034–T045 完整本地玩法扩展** · Windows 桌面浏览器单人像素风生存游戏

ZERO 可部署于三张战场：科技实验室、东城区疏散线或失控能源枢纽。六种自动武器、四种进化、十二种道具、敌潮事件、开放地图危机、三套能源布局和两阶段电网监护者组成多种战局。标准生存不限武器栏；战术构筑最多携带三种武器。守住五分钟并击败首领可获胜，也可携带原构筑开启无尽加时。公开试玩链接仍运行 V1.0.0；T034–T045 扩展保留在本地版本，未发布到该站点。

**在线试玩：** [打开 Protocol Zero](https://protocol-zero-game.mingw0788.chatgpt.site)

**本地试玩：**在项目目录运行 `npm ci`、`npm run dev`，再打开命令显示的本机网址。

**T034–T045 扩展路线已完成自动验收：**新增统计结算、双道具槽、三类动态事件、三种战术敌人、环境危机、六武器与四种进化、十二种道具、能源枢纽三布局、协议/挑战、图鉴/成就、本地档案导入导出及无尽加时。自动模拟、浏览器和整帧性能证据见 [T045 综合验收报告](docs/task-report-T045.md)。真人自然整局、主观试听与发布门槛仍须单独验收。

## 运行要求

- Windows 11 桌面版 Microsoft Edge 或 Chrome。T045 在 Edge 152 有窗口和 Chrome 155 无窗口模式检查 UI；浏览器、机器和压力场景边界见验收报告。其他系统尚未验证。
- Node.js `^22.12.0 || ^24.0.0 || >=26.0.0` 与 npm 11.13.0。

## 安装和启动

```sh
npm ci
npm run dev
```

打开开发服务器显示的本机网址。命令行工具和测试：

```sh
npm test          # 运行 Vitest 测试
npm run build     # 生成静态生产文件到 dist/
npm run preview   # 本机预览 dist/ 生产构建
```

构建产物可部署到静态文件托管服务，无需游戏后端、账号或游戏 API。`dist/` 不提交到源码仓库。

## 操作

| 输入 | 操作 |
|---|---|
| W/A/S/D 或方向键 | 八方向移动；斜向速度已归一化 |
| 自动 | 脉冲枪自动攻击射程内最近敌人；轨道刃解锁后自动环绕攻击 |
| Esc | 在战斗与暂停之间切换；升级选择期间不能跳过 |
| 鼠标 | 开始、帮助、音效设置、选择升级，以及操作暂停/结算菜单 |
| E / Q | 分别使用第 1 / 第 2 主动道具槽：部署诱饵、释放 EMP，或在城区中继旁使用电芯 |
| C / F | C 切换高亮道具槽；F 与 64 像素内最近的主动道具交换，空槽时直接拾取 |
| G | 在事件、未完成终端、救援补给和中继之间切换追踪目标 |
| Shift | 沿移动方向/朝向冲刺，免接触伤害，冷却 4 秒 |
| 1 / 2 / 3；R | 升级时选择对应卡片；重抽（初始 2 次，完成全部终端再加 1 次） |
| 地图选择 | 主菜单选择废弃科技实验室、东城区疏散线或失控能源枢纽 |

暂停菜单的“返回主菜单”会先确认；取消后仍保持暂停。切换到后台会自动暂停，回到游戏页面后需手动继续。升级面板出现时战斗冻结，选择一项后继续。

## V1 内容与记录

- V1 基线：ZERO、科技实验室、三种普通敌人、脉冲枪/轨道刃、六类升级和单阶段 Boss T-01。
- V2 本地扩展：
  - **三张地图与环境：**能源枢纽的三套布局、轮替电弧走廊、终端断电、可反复补能的反应堆和两阶段首领。
  - **六种自动武器：**脉冲枪、轨道刃、弧光线圈、磁轨炮、冷凝喷射器和最多三架蜂群无人机。升级可选择四种进化；菜单展示配方与栏位规则。
  - **十二种道具：**两格 E/Q 主动槽、近距交换、击杀补给、救援站奖励，以及炮台、冷凝炸弹、维修场与中继增幅。
  - **战局模式：**三类动态事件、护盾与冲刺、三种开局协议、三种挑战词条，以及胜利后保留成绩的无尽加时。
  - **记录与反馈：**按地图/模式/协议/挑战分开记录、发现图鉴、八项成就、纯外观奖励、本地 JSON 档案备份/恢复、伤害数字/低闪光选项与独立音乐音量。
  - HUD 显示本级经验与升级门槛、护盾/冲刺、目标/雷达、装备、首领和环境状态。参数及验收证据见 [T045 综合报告](docs/task-report-T045.md)。
- 五分钟挑战、暂停、升级选择、胜负结算、重开与返回主菜单。
- 原创代码像素图案、Canvas 动画、Web Audio 合成短音效和程序生成音乐；声音设置及战绩档案保存在本机浏览器。
- 刷新或重新开始不会恢复进行中的战局；JSON 档案导入会先展示内容再确认替换。

## 验证范围与已知限制

- 本地完整回归：81 个测试文件、564 项通过；生产构建转换 105 个模块（T045）。
- V2 初始内容包验收记录见 [V2 内容包交付报告](docs/task-report-V2-content-pack.md)；当前体验增量与最新回归证据见 [T031 报告](docs/task-report-T031.md)。
- 东城区新增医疗广场、变电庭院与疏散集结区中继站。沿 HUD 方向找到圆环，累计站入 2 秒恢复 15 生命并释放电磁冲击；能量耗尽后可通过附近击杀或电芯补充，重新蓄能再用。地图装饰仍可通行。枪口反馈开火，敌人受击闪白；弧光与磁轨炮有独立音色。
- T045 使用 Edge 152 有窗口和 Chrome 155 无窗口模式检查 640×360 / 1440×900 菜单/帮助、键盘移动/升级选择、E/Q 道具、暂停/失焦暂停、胜利/无尽、十次重开和档案导入导出。失焦用浏览器事件验证；操作系统实际切换标签页尚未验证。
- 托管站点上，Chrome 154 完成开局、暂停/返回、失败终局/重开，以及通过受控夹具验证胜利终局/重开；Edge 152 完成菜单、设置、开始、暂停/返回。Edge 的隐藏窗口长局自动化会触发预期的失焦暂停；Edge 本地生产预览的终局和重开通过。详见 [`docs/task-report-T021.md`](docs/task-report-T021.md)。
- T020 的一次自然键盘战局在 00:32、16 次击杀时失败，未进入第一次升级；因此自然完整五分钟战局与 Boss 平衡仍未验证。另有受控流程验证胜负边界，但它不代表自然通关。
- M3 至少比较两种自然升级组合、M4 完成一整局人工战局这两项质量门禁尚未通过；任务实现和 V1.0.0 静态发布已完成不代表人工玩法验收完成。补测条件与记录模板见 [`docs/gameplay-acceptance-follow-up.md`](docs/gameplay-acceptance-follow-up.md)。

- 游戏使用浏览器存储；清除站点数据或更换浏览器配置会移除本地成绩和设置。

详细验收证据及限制见 [`docs/task-report-T020.md`](docs/task-report-T020.md) 和发布记录 [`docs/task-report-T021.md`](docs/task-report-T021.md)。
